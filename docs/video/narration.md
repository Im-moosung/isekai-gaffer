# 시연영상 가이드 내레이션 대본

> **이 대본은 사용자가 별도 TTS로 만들 "가이드 목소리"다.**
> 게임 안에서 나는 캐스터·해설위원 음성과는 **완전히 다른 트랙**이다.
>
> 목적은 하나다 — **심사자가 이 게임으로 무엇을 할 수 있는지 알게 하는 것.**
> 분위기가 아니라 **기능**을 말한다. 버튼 이름을 부르고, 무엇이 바뀌는지 말하고,
> 다음에 무엇을 보여줄지 예고한다.

## 두 목소리 구분

| | 가이드 목소리 (이 대본) | 게임 중계 |
|---|---|---|
| 정체 | 게임을 안내하는 사람 | 경기 캐스터·해설위원 |
| 말투 | 설명체 | 중계체 |
| 제작 | 사용자가 TTS로 별도 | 이미 게임에 있음 |
| 볼륨 | 0 dB | −12 dB (겹칠 때) |

# S1 · 타이틀 화면 — 0:00 ~ 0:38

**화면**: 랜딩. 버튼 두 개가 다 보이게. `[캠페인 시작]`에 커서를 올렸다가, `[리더보드 보기]`도 한 번 짚고 다시 `[캠페인 시작]`으로.

```
현실에서 축덕인 내가, 이세계에선 국대 감독.
2026년 월드컵을 다시 지휘하는 축구 감독 시뮬레이션입니다.

실제로 대한민국은 1승 2패로 조별리그에서 탈락했습니다.
그 대회를 처음부터 다시 치릅니다.

시작 화면에는 버튼이 두 개 있습니다.

캠페인 시작은 조별리그 세 경기부터 결승까지,
최대 여덟 경기를 이어서 치르는 본편입니다.

리더보드 보기는 다른 감독들의 순위표입니다.
여정이 끝나면 점수가 여기 기록됩니다.
그 화면은 영상 마지막에 다시 보여 드리겠습니다.

캠페인 시작을 누르겠습니다.
```

**읽기**: `1승 2패` → "일승 이패" / `여덟 경기` → 숫자로 새지 않는지 확인

# S2 · 여정 화면 — 0:38 ~ 1:19

**화면**: 캠페인 여정. 조별리그 3경기 + 토너먼트가 세로로 나열된 화면. 다음 상대 카드(체코)를 짚고, 토너먼트 `[펼치기]`도 한 번 눌러 보여준다.

```
전체 일정입니다.
조별리그 세 경기를 치르고, 조 2위 안에 들면 토너먼트로 갑니다.
결승까지 가면 최대 여덟 경기입니다.

조별 세 경기에는 실제 역사의 결과가 기준선으로 적혀 있습니다.
첫 상대 체코전은 실제로 2대 1로 이긴 경기입니다.
후반에 한 골을 먼저 내주고 황인범과 오현규가 뒤집었습니다.

토너먼트 대진은 조별리그를 통과해야 정해집니다.

한 가지 중요한 점이 있습니다.
경기는 따로 노는 게 아니라 이어집니다.
선수의 체력과 사기가 다음 경기로 넘어가고,
경고를 두 장 받으면 다음 경기에 못 나옵니다.

그래서 오늘 누구를 혹사시킬지가 다음 경기를 좌우합니다.

체코전 준비하기를 누르면 전술 센터로 들어갑니다.
```

# S3 · 선발 라인업 — 1:19 ~ 2:22

**화면**: 전술 센터 `[선발 라인업]` 탭. 위 탭 세 개(선발 라인업 / 팀 전술 / 상대 브리핑)를 커서로 훑고 시작.

```
전술 센터입니다. 탭이 세 개 있습니다.
선발 라인업, 팀 전술, 상대 브리핑.

먼저 선발 라인업입니다.

포메이션은 여섯 가지 중에 고릅니다.
4-2-3-1에서 3-5-2로 바꾸면 열한 명이 자동으로 재배치됩니다.

선수는 끌어서 옮깁니다.
집으면 선수가 커서를 따라오고,
다른 선수 위에 올리면 표시가 뜹니다.
여기서 놓으면 두 선수의 자리가 바뀝니다.

벤치 선수 위에 놓으면 교체가 됩니다.
드래그가 어려우면 두 명을 클릭해서 버튼으로도 바꿀 수 있습니다.
키보드로도 됩니다. 스페이스로 집고, 화살표로 옮기고, 다시 스페이스로 놓습니다.

선수를 클릭하면 상세 카드가 열립니다.
속도, 패스, 슛, 수비 같은 능력치를 육각형으로 보여 주고,
지금 체력과 사기도 함께 나옵니다.

두 명을 고르면 두 선수를 나란히 비교합니다.

오른쪽 배치 점검에서 자리에 안 맞는 선수를 알려 줍니다.
```

**읽기**: `4-2-3-1` → **"사 이 삼 일"** / `3-5-2` → **"쓰리 파이브 투"** 또는 "삼 오 이" — TTS로 들어 보고 자연스러운 쪽

# S4 · 팀 전술 — 2:22 ~ 3:12

**화면**: `[팀 전술]` 탭. 서브탭 세 개(지시 / 태세 / 세트피스·대형)를 훑고, 각각 하나씩 조작.

```
두 번째 탭, 팀 전술입니다. 서브탭이 세 개입니다.

태세부터 보겠습니다.
매우 수비적부터 매우 공격적까지 다섯 단계입니다.
공격적으로 올리면 왼쪽 작전판에서 팀의 무게중심이 앞으로 이동합니다.
숫자가 아니라 그림으로 확인할 수 있습니다.

라인별 적극성도 따로 정합니다.
수비, 미드필드, 공격을 각각 자제, 기본, 적극으로 나눕니다.

지시 탭에서는 수비 라인 높이와 압박 강도, 템포를 조절합니다.
슬라이더를 올리면 작전판의 수비 라인이 같이 올라갑니다.

세트피스 탭에서는 코너킥 전술을 정합니다.
니어 포스트냐 파 포스트냐, 박스에 몇 명을 넣느냐.
이 선택은 실제 코너킥 득점 확률에 반영됩니다.
```

**읽기**: `다섯 단계` / `몇 명` — 숫자 확인

**화면**: `[상대 브리핑]` 탭. 상대 포메이션, 키 플레이어 ★, 매치업 힌트.

```
세 번째 탭은 상대 브리핑입니다.

상대의 예상 포메이션과 선발 열한 명,
별표가 붙은 선수가 경계해야 할 핵심 선수입니다.

내 포메이션과 상대 포메이션의 상성도 수치로 나옵니다.

전술이 정해졌으면 킥오프를 누릅니다.
```

# S6 · 경기와 중계 — 3:29 ~ 4:12

**화면**: 3D 경기. 골 장면 포함.

```
경기가 시작됩니다.

중계는 실제 음성으로 나옵니다.
캐스터와 해설위원 두 사람이고,
천 개가 넘는 음성 조각을 미리 만들어 두었습니다.
```

> **여기서 말을 멈춘다.** 게임 중계를 10초 이상 그대로 들려준다.
> 골 장면과 해설이 이 게임의 증명이다.

**화면**: 설정 팝업을 열어 3D/2D 전환을 보여주고, 속도 버튼도 누른다.

```
경기 화면은 3D와 2D를 오갈 수 있습니다.
2D 작전판으로 바꾸면 선수 위치와 전술이 더 잘 보입니다.

재생 속도도 조절합니다. 한 배, 1.5배, 두 배입니다.

오른쪽 위 설정에서 음소거와 해설 끄기도 가능합니다.

화면 아래 티커에는 슈팅, 점유율, 파울 같은 실시간 기록이 흐릅니다.
```

# S7 · 감독 개입 — 4:12 ~ 5:06

**화면**: 순간 제안 배너 → `[사용]` → 작전판 → 팀토크 → 교체 → `[전술 확정]`.

```
경기 중에는 감독 타임을 쓸 수 있습니다.
경기당 다섯 번, 한 번 쓰면 십 분을 기다려야 합니다.

흐름이 넘어가거나 골이 나면 화면에 제안이 뜹니다.
사용을 누르면 경기가 멈추고 작전판이 열립니다.

하프타임에는 팀 토크를 합니다.
분노, 격려, 침착, 신뢰 중에 하나를 고르면
선수들의 사기가 바로 바뀝니다.

교체는 경기당 다섯 명, 기회는 세 번입니다.
나갈 선수와 들어올 선수를 고르고 확정합니다.

경기를 멈추지 않고 터치라인에서 외칠 수도 있습니다.
독려, 더 뛰어, 침착, 칭찬 네 가지이고 오 분마다 한 번씩입니다.

전술 확정을 누르면 경기가 다시 시작됩니다.
```

**화면**: 토너먼트 승부차기 장면이 있으면 짧게 (없으면 이 블록은 뺀다)

```
토너먼트에서 비기면 승부차기로 갑니다.
키커 다섯 명의 순서를 직접 정하고,
한 명씩 방향을 고릅니다.
```

**읽기**: `다섯 번` `십 분` `다섯 명` `세 번` `오 분` — 전부 한글 읽기 확인

```

# S9 · 신문과 리더보드 — 5:29 ~ 6:12

**화면**: 신문 카드 → `[이미지 저장]` 짚기 → 리더보드.

```
경기 결과는 신문 한 면으로 나옵니다.
헤드라인은 방금 한 답변을 반영해서 만들어집니다.
이미지로 저장해서 공유할 수도 있습니다.

이렇게 여덟 경기를 치르면 여정이 끝납니다.
탈락한 라운드까지가 당신의 기록이고, 우승하면 우승으로 남습니다.

엔딩 화면에서 전체 여정을 돌아봅니다.
어느 경기에서 이기고 졌는지, 총점이 얼마인지.

여기서 닉네임을 입력하면 리더보드에 등록됩니다.
도달한 라운드와 승점, 득실, 무실점 경기를 합산한 점수입니다.

앞에서 말씀드린 그 순위표입니다.
전체 순위 보기를 누르면 다른 감독들의 기록이 나옵니다.
```

두 번째 탭, 팀 전술입니다. 서브탭이 세 개입니다. 태세부터 보겠습니다. 매우 수비적부터 매우 공격적까지 다섯 단계입니다. 공격적으로 올리면 왼쪽 작전판에서 팀의 무게중심이 앞으로 이동합니다. 숫자가 아니라 그림으로 확인할 수 있습니다. 라인별 적극성도 따로 정합니다. 수비, 미드필드, 공격을 각각 자제, 기본, 적극으로 나눕니다. 지시 탭에서는 수비 라인 높이와 압박 강도, 템포를 조절합니다. 슬라이더를 올리면 작전판의 수비 라인이 같이 올라갑니다. 세트피스 탭에서는 코너킥 전술을 정합니다. 니어 포스트냐 파 포스트냐, 박스에 몇 명을 넣느냐. 이 선택은 실제 코너킥 득점 확률에 반영됩니다.
```

**S5**
```
세 번째 탭은 상대 브리핑입니다. 상대의 예상 포메이션과 선발 열한 명, 별표가 붙은 선수가 경계해야 할 핵심 선수입니다. 내 포메이션과 상대 포메이션의 상성도 수치로 나옵니다. 전술이 정해졌으면 킥오프를 누릅니다.
```

**S6-a**
```
경기가 시작됩니다. 중계는 실제 음성으로 나옵니다. 캐스터와 해설위원 두 사람이고, 천 개가 넘는 음성 조각을 미리 만들어 두었습니다.
```

**S6-b**
```
경기 화면은 3D와 2D를 오갈 수 있습니다. 2D 작전판으로 바꾸면 선수 위치와 전술이 더 잘 보입니다. 재생 속도도 조절합니다. 한 배, 1.5배, 두 배입니다. 오른쪽 위 설정에서 음소거와 해설 끄기도 가능합니다. 화면 아래 티커에는 슈팅, 점유율, 파울 같은 실시간 기록이 흐릅니다.
```

**S7-a**
```
경기 중에는 감독 타임을 쓸 수 있습니다. 경기당 다섯 번, 한 번 쓰면 십 분을 기다려야 합니다. 흐름이 넘어가거나 골이 나면 화면에 제안이 뜹니다. 사용을 누르면 경기가 멈추고 작전판이 열립니다. 하프타임에는 팀 토크를 합니다. 분노, 격려, 침착, 신뢰 중에 하나를 고르면 선수들의 사기가 바로 바뀝니다. 교체는 경기당 다섯 명, 기회는 세 번입니다. 나갈 선수와 들어올 선수를 고르고 확정합니다. 경기를 멈추지 않고 터치라인에서 외칠 수도 있습니다. 독려, 더 뛰어, 침착, 칭찬 네 가지이고 오 분마다 한 번씩입니다. 전술 확정을 누르면 경기가 다시 시작됩니다.
```

**S7-b**
```
토너먼트에서 비기면 승부차기로 갑니다. 키커 다섯 명의 순서를 직접 정하고, 한 명씩 방향을 고릅니다.
```

**S8**
```
경기가 끝나면 기자회견이 열립니다. 질문은 정해져 있지 않습니다. 감독이 실제로 한 선택에서 만들어집니다. 교체를 했으면 교체를 묻고, 전술을 바꿨으면 그것을 묻습니다. 답변은 세 가지 톤입니다. 공격적, 겸손, 유머. 어떻게 답하느냐가 다음 화면을 바꿉니다.
```

**S9**
```
경기 결과는 신문 한 면으로 나옵니다. 헤드라인은 방금 한 답변을 반영해서 만들어집니다. 이미지로 저장해서 공유할 수도 있습니다. 이렇게 여덟 경기를 치르면 여정이 끝납니다. 탈락한 라운드까지가 당신의 기록이고, 우승하면 우승으로 남습니다. 엔딩 화면에서 전체 여정을 돌아봅니다. 어느 경기에서 이기고 졌는지, 총점이 얼마인지. 여기서 닉네임을 입력하면 리더보드에 등록됩니다. 도달한 라운드와 승점, 득실, 무실점 경기를 합산한 점수입니다. 앞에서 말씀드린 그 순위표입니다. 전체 순위 보기를 누르면 다른 감독들의 기록이 나옵니다.
```

**S10**
```
현실에서 축덕인 내가, 이세계에선 국대 감독. 지금 바로 플레이할 수 있습니다.
```

## 반드시 담아야 할 것 (해커톤 규정)

> 시연 영상 포함 내용: 시작 화면 → 선수 배치·전술 설정 → 핵심 인터랙션 → 결과 화면

- [ ] 시작 화면 (S1)
- [ ] 선수 배치 — **드래그앤드롭** (S3)
- [ ] 전술 설정 — 슬라이더·포메이션 (S4)
- [ ] 핵심 인터랙션 — 경기 중 감독 개입 (S7)
- [ ] 결과 화면 — 기자회견·신문·리더보드 (S8·S9)

## 품질

- [ ] 1920×1080 이상
- [ ] **커서가 화면에 보이게** 녹화 — 조작임을 알려야 한다
- [ ] 드래그는 실제보다 30% 느리게. 급하면 조작이 아니라 편집으로 보인다
- [ ] 로딩·빈 화면 구간은 잘라낸다
- [ ] 오탈자·깨진 레이아웃이 한 프레임도 없는지 확인 (안정성 25점)

## 소리

- [ ] 게임 중계 음성은 **S6에서만** 살린다
- [ ] BGM은 게임 것을 그대로 쓴다 (직접 만든 자산이라 저작권 문제 없음)
- [ ] 내레이션과 게임 소리가 겹치면 게임을 −12 dB로 내린다

## 하지 말 것

- [ ] 화려한 전환 효과 — 전환이 눈을 끌면 손해다
- [ ] 빠른 컷 편집 — 각 화면이 읽힐 시간을 준다
