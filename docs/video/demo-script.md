# 시연영상 시나리오

> 대상: 데이커 월간 해커톤 "내가 축구 감독이라면" 최종 제출물 ③ 시연영상(유튜브)
> 목표 길이: **2분 40초** (±20초)
> 내레이션은 사용자가 별도 TTS로 제작한다. 이 문서는 **화면 구성 + 내레이션 대본 + 자막**이다.

## 규정이 요구하는 것 (역산)

| 규정 문구 | 대응 씬 |
|---|---|
| 시작 화면 | S1 |
| 선수 배치·전술 설정 | S2 · S3 |
| 핵심 인터랙션 | S4 · S5 |
| 결과 화면 | S6 · S7 |

배점: **참신성 30 / 몰입감·조작감 25 / 안정성 25**.
1차가 대중 투표이므로 **첫 15초가 이탈을 가른다.**

## 이 영상이 팔아야 할 세 가지

1. **대체역사** — 실제로 진 경기를 다시 지휘한다. 흔한 전술보드 클론이 아니다 (참신성)
2. **감독의 손** — 드래그·슬라이더·개입이 실제로 결과를 바꾼다 (조작감)
3. **경기가 말을 한다** — 실제 음성 중계·기자회견·신문 (몰입감)

## 내레이션 원칙

- **한 문장 12자~25자.** TTS는 긴 문장에서 호흡이 무너진다
- **숫자는 한글로 쓴다** — "5회" 대신 "다섯 번". TTS가 숫자를 영어로 읽는 사고를 막는다
- **화면에 보이는 것을 설명하지 않는다.** 화면이 못 하는 말만 한다
- 자막은 내레이션과 **같은 문장**을 쓴다(따로 쓰면 읽는 부담이 두 배)

---

# S1 · 오프닝 (0:00 – 0:18)

**화면**
랜딩 화면. 스타디움 배경에 조명이 켜져 있고 타이틀이 중앙에 있다.
`0:10`에 [캠페인 시작] 버튼으로 커서가 이동, `0:16`에 클릭.

**내레이션**
```
2026년 6월.
대한민국은 1승 2패로 조별리그를 마쳤습니다.
그 대회를, 당신이 다시 지휘합니다.
90분과 다섯 번의 개입.
그것이 당신에게 주어진 전부입니다.
```

**자막**
내레이션과 동일. 하단 중앙, 2줄 이내로 끊는다.

**연출 메모**
- 첫 3초는 **말 없이 화면만** 보여준다. 타이틀이 읽힐 시간을 준다
- 배경음악은 게임의 랜딩 BGM을 그대로 쓴다(따로 구할 필요 없다)
- 커서 이동은 천천히. 급하면 조작이 아니라 편집으로 보인다

---

# S2 · 선수 배치 (0:18 – 0:52)

**화면**
전술 센터 → [선발 라인업] 탭.
1. 포메이션 보드와 벤치가 함께 보이는 전체 샷 (2초)
2. **선수를 집어 끌고 간다** — 고스트가 커서를 따라다니는 것이 보이게
3. **다른 선수 위에 올린다** — 교환 이펙트가 뜨는 순간에서 **0.5초 정지**
4. 놓는다. 두 선수가 자리를 바꾼다
5. 포메이션 셀렉터로 `4-2-3-1` → `3-5-2` 변경. 보드가 재배치되는 것을 보여준다

**내레이션**
```
먼저 열한 명을 세웁니다.
선수를 끌어서 자리를 바꿉니다.
누구와 바뀌는지, 놓기 전에 보입니다.
포메이션을 바꾸면 열한 명이 다시 섭니다.
```

**연출 메모**
- **③번 순간이 이 씬의 핵심이다.** 배점에 "드래그앤드롭 등 인터랙션 품질"이 직접 걸려 있다
- 드래그는 **느리게**. 실제 조작 속도보다 30% 느리게 움직여야 화면에서 읽힌다
- 벤치 선수를 필드로 올리는 것과 필드끼리 바꾸는 것, **둘 다** 보여준다

---

# S3 · 전술 설정 (0:52 – 1:20)

**화면**
1. [팀 전술] 탭 → **[태세] 서브탭**. 멘탈리티를 `균형` → `매우 공격적`으로
   → **무게중심 마커가 앞으로 이동하는 것**을 잡는다 (1.5초 정지)
2. **[지시] 서브탭** → 라인 슬라이더를 올린다 → 보드의 수비 라인이 함께 올라간다
3. **[상대 브리핑] 탭** → 상대 포메이션, 키 플레이어 ★, 매치업 힌트

**내레이션**
```
다음은 팀의 태세입니다.
공격적으로 바꾸면, 팀의 무게중심이 앞으로 나갑니다.
라인을 올리면 수비가 함께 올라옵니다.
숫자가 아니라 그림으로 확인합니다.
상대의 강점과 약점도 미리 읽습니다.
```

**연출 메모**
- 슬라이더를 움직일 때 **보드가 같이 반응하는 것**이 요점이다. 슬라이더만 클로즈업하면 의미가 없다
- 무게중심 마커는 작으니 **화면을 확대**하거나 그 부분만 크롭해서 보여주는 편이 낫다

---

# S4 · 경기 · 중계 (1:20 – 1:52)

**화면**
1. 킥오프. 3D 피치 전체 샷
2. **골 장면** — 중계 음성이 나오는 구간을 그대로 살린다
3. 스코어버그·이벤트 티커

**내레이션**
```
경기가 시작되면, 중계가 따라붙습니다.
캐스터와 해설위원, 두 사람의 목소리입니다.
전부 미리 만들어 둔 음성입니다.
```

**연출 메모**
- **이 구간은 게임 소리를 살린다.** 내레이션을 그 위에 겹치지 말고, 중계가 끝난 뒤 얹거나 볼륨을 낮춘다
- 내레이션 볼륨 −6dB, 게임 소리 0dB로 두면 중계가 들린다
- **골이 나는 시점을 미리 알고 있으므로**(결정론) 그 앞뒤만 잘라 쓰면 된다

---

# S5 · 감독 개입 (1:52 – 2:15)

**화면**
1. 순간 제안 배너 — `실점 직후 — 벤치가 술렁입니다` 또는 `득점 직후`
2. [사용] 클릭 → 작전판이 열린다
3. **팀토크** 네 장 중 하나 선택 → 사기 변화 배너
4. **교체** — 나갈 선수 / 들어올 선수
5. 재개. 남은 개입 횟수가 줄어드는 HUD

**내레이션**
```
경기 중에도 손을 쓸 수 있습니다.
다만 다섯 번뿐입니다.
한 번 쓰면 십 분을 기다려야 합니다.
라커룸에서 무슨 말을 할지,
누구를 뺄지, 전부 당신이 정합니다.
```

**연출 메모**
- **"자원이 유한하다"가 이 씬의 메시지다.** 남은 횟수 표시를 반드시 화면에 담는다
- 팀토크 선택지 네 장(분노·격려·침착·신뢰)이 다 보이는 프레임을 한 번 넣는다
- 교체는 드래그가 아니라 목록 선택이므로 **빠르게** 넘어간다

---

# S6 · 기자회견 (2:15 – 2:32)

**화면**
1. 기자회견 화면 전체 — 실루엣과 질문 카드가 함께 보이게
2. 질문 한 개 읽히는 시간 (1.5초)
3. 답변 세 장 중 하나 선택 — 톤이 다르다는 것이 보이게

**내레이션**
```
경기가 끝나면 기자들이 기다립니다.
질문은 당신이 실제로 한 선택에서 나옵니다.
어떻게 답하느냐에 따라, 내일 신문이 달라집니다.
```

**연출 메모**
- 질문 문장을 **화면에서 읽을 수 있을 만큼** 머문다. 이 게임에서 가장 "읽는" 화면이다
- 답변 세 장의 톤 칩(공격적·겸손·유머)이 보이는 프레임을 넣는다

---

# S7 · 신문과 리더보드 (2:32 – 2:50)

**화면**
1. 신문 카드 등장 — 헤드라인이 읽히도록 2초
2. 리더보드 화면 — 순위표
3. 마지막: 랜딩으로 돌아가거나 타이틀 로고 + 배포 URL

**내레이션**
```
결과는 신문 한 면으로 남습니다.
헤드라인은 당신의 답변에서 만들어집니다.
그리고 당신의 여정은 순위표에 기록됩니다.
당신의 2026년은, 어떻게 끝납니까.
```

**연출 메모**
- **마지막 문장 뒤에 1.5초 여백**을 둔다. 여운 없이 끝나면 인상이 남지 않는다
- 배포 URL을 마지막 프레임에 텍스트로 넣는다 — 심사자가 바로 눌러 볼 수 있다

# 촬영 체크리스트

## 반드시 담아야 할 것 (규정)
- [ ] 시작 화면
- [ ] 선수 배치 (드래그앤드롭)
- [ ] 전술 설정 (슬라이더·포메이션)
- [ ] 핵심 인터랙션 (경기 중 개입)
- [ ] 결과 화면 (기자회견·신문·리더보드)

## 품질
- [ ] **1920×1080 이상**, 60fps 권장
- [ ] 커서가 화면에 보이게 녹화 (조작임을 알려야 한다)
- [ ] 로딩·빈 화면 구간은 잘라낸다
- [ ] 오탈자·깨진 레이아웃이 한 프레임도 없는지 확인 (안정성 25점)

## 소리
- [ ] 게임 중계 음성은 **S4에서만** 살린다
- [ ] BGM은 게임 것을 그대로 쓴다 (저작권 문제 없음 — 직접 만든 자산)
- [ ] 내레이션과 게임 소리가 겹치면 내레이션이 이긴다 (게임 −12dB)

## 하지 말 것
- [ ] 화려한 전환 효과 — 3분 안에 게임을 이해시켜야 한다. 전환이 눈을 끌면 손해다
- [ ] 빠른 컷 편집 — 각 화면이 읽힐 시간을 준다
- [ ] 기능 나열 — 안 보여준 기능이 있어도 괜찮다. 다 보여주려다 아무것도 안 남는다

# 시드 선택

이 게임은 **결정론**이다. 같은 시드는 사건 하나까지 똑같이 재현된다.
따라서 **좋은 경기가 나오는 시드를 미리 찾아 두면**, 마음에 들 때까지 다시 찍을 수 있다.

바람직한 경기의 조건:
- 전반에 실점 → 후반에 역전 (개입의 값어치가 보인다)
- 골이 2~4개 (0골은 심심하고 6골은 산만하다)
- 극장골이나 퇴장이 있으면 더 좋다

시드 탐색 결과는 `docs/video/seed-candidates.md`에 기록한다.
