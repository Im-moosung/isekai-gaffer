# 시연영상용 시드 후보

조별리그 1차전 **대한민국 vs 체코**로 400개 시드를 전수 탐색했다.
조건: 총 득점 2~5골 + (전반 실점 후 역전 ∨ 85분 이후 득점). **85개가 통과했다.**

이 게임은 **결정론**이다 — 같은 시드는 사건 하나까지 똑같이 재현된다.
촬영이 마음에 안 들면 같은 경기를 몇 번이고 다시 찍을 수 있다.

## 권장 — 시드 28 (2-1)

```
36' 체코 선제골 (파트리크 시크)
48' 오현규 동점골
54' 백승호 경고
95' 손흥민 결승골 ★ 극장골
```

**왜 이 시드인가**

- **서사가 교과서적이다.** 지고 있다 → 따라붙는다 → 마지막에 뒤집는다. 설명이 필요 없다
- **후반 시작 3분 만에 동점**이라 하프타임 팀토크의 값어치가 그대로 드러난다. "라커룸에서 무슨 말을 했느냐"가 화면에서 증명된다
- **95분 결승골.** 극장골 중계 클립이 붙어 있고(가장 흥분한 톤), 영상의 클라이맥스가 자연스럽게 만들어진다
- 이벤트 56개로 적당하다 — 산만하지 않고 심심하지 않다
- 골이 3개라 각각에 시간을 줄 수 있다

**촬영 시 개입 배치 (권장)**

| 시점 | 행동 | 영상에서의 의미 |
|---|---|---|
| 하프타임 (0-1) | **팀토크 — 격려** | 지고 있을 때 감독의 말 |
| 후반 시작 | 라인 올리기 | 지시가 그림으로 바뀐다 |
| 48' 동점 직후 | (제안 배너가 뜬다) | 순간 제안 UI 노출 |
| 70' 전후 | **교체** | 자원 소모가 보인다 |
| 남은 횟수 표시 | — | "다섯 번뿐"이 사실임을 증명 |

## 차선 — 시드 249 (2-1)

```
32' 체코 선제골 (아담 흘로제크)
69' 이재성 동점골
90' 이재성 결승골 ★ 멀티골
```

**한 선수가 두 골**을 넣는다. "이재성 멀티골"이라는 이야기가 하나 더 생기고, 멀티골 전용 중계 대사가 나온다. 다만 68분간 지고 있어 **중반이 길다** — 편집으로 잘라야 한다.

## 차선 — 시드 398 (2-1)

```
12' 체코 선제골  →  22' 손흥민 동점  →  95' 오현규 결승골
```

초반에 두 골이 몰려 **도입이 빠르다.** 대신 22분부터 95분까지 골이 없어 중간이 비고, 경고가 5장이라 화면이 어수선하다.

## 쓰지 않기로 한 것 — 시드 6 (2-1)

```
2' 손흥민 선제골  →  4' 체코 동점  →  86' 이재성 결승골
```

2분·4분에 골이 연달아 터져 **오프닝은 화려하다.** 하지만 "지고 있다가 뒤집는다"는 서사가 없어 **감독 개입의 값어치를 보여주지 못한다.** 이 영상이 팔아야 할 것과 어긋난다.

## 시드를 지정하는 법

주소 끝에 `?seed=28`을 붙인다.

```
http://localhost:5174/?seed=28
```

이 파라미터는 화면에 노출되지 않지만 코드에는 살아 있다(`src/App.tsx`).
시드 공유 UI는 제품에서 제거했으나, **촬영·디버깅용 경로는 남겨 두었다.**

## 주의

여기 적힌 결과는 **감독이 아무 개입도 하지 않았을 때**의 경기다.
촬영 중 팀토크·교체·지시 변경을 하면 **그 시점 이후가 달라진다** — 그게 이 게임의 요점이다.

따라서 촬영은 이렇게 한다:
1. 먼저 개입 없이 한 번 돌려 흐름을 확인한다
2. 개입 지점을 정한다 (위 표 참고)
3. 같은 시드로 다시 돌리며 정해진 지점에서 개입한다
4. 결과가 마음에 안 들면 3번을 반복한다 — **개입 전까지는 항상 같은 경기다**
