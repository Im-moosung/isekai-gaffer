## L1. ★ §2.2 "권한 확장 서사" — 폐기·재구성 (B안 확정)

**현재 기획서(`proposal-draft.md:42`)**
> 조별리그 (역사 구간 — 역사 수정): 실제 3경기를 재현. **전반은 실제 역사대로 압축 재생**되며, 사용자는 관찰 노트 태깅의 제한적 개입만 수행. **하프타임에 전권 인수** — 팀토크·전술 재구성·교체로 후반전 지휘.

**문제**: Phase A가 이미 이 구조를 깼다. 지금은 조별리그 포함 **모든 경기에서 킥오프 전에 전권**을 갖는다(전술 센터). 여기에 B안(전반도 완전 시뮬)이 확정되면 "전반 관찰 구간"이 아예 사라진다.

**재구성 방향 — 축을 "권한"에서 "기준선"으로**
- 조별리그(역사 구간): 실제 결과가 **벤치마크로 화면에 놓인다**("참고 · 실제 역사 2-1" — 이미 구현됨). 유저는 그것을 뛰어넘어야 한다.
- 토너먼트(미지 구간): 비교 대상이 없다.
- 역사 구간/미지 구간 이분 구조와 "역사 수정 최소 조건 = 2위" 관문은 **그대로 살아난다.**

**연동 수정 위치**: `:42`, `:94`(전반 행), `:117`, `:164`, `:166~169`

## L4. 두루뭉술하게 쓸 것 (미확정·진행 중)

아래는 **구체적으로 쓰지 마라.** 방향만 서술한다.

- **경기 화면 정합성(Phase B)** — 현재 이벤트와 화면이 어긋나는 문제를 고치는 중. "중계 화면과 경기 데이터의 정합" 정도로만.
- **입장 연출·선수 소개** — 채택 권고 상태이나 미착수. 넣을지 확정 전.
- **선수 3D 리깅 에셋** — **도입하지 않기로 결론.** 기획서에 리깅·모캡을 언급하지 마라.
- **선수 개인 경기 스탯** — 이벤트 파생분만 1차 구현 중. 패스 성공률·터치 수는 미정.
- **코치진 조언 국면화** — 진행 중.
- **잔여 엔진 밸런스 3건**(`very-attacking` 지배 등) — 미해결. 밸런스를 "완성"이라 단정하지 마라.

## L5. 사실 확인이 필요한 기존 서술

- `:130` "AI 기본 상태의 시뮬 결과가 실제 대회 평균 스탯에 수렴" — 캘리브레이션은 여전히 통과하나 최악 편차 24.6%다. "±25% 이내" 같은 구체 수치를 쓸 거면 실측과 맞춰라.
- `:134` 데이터 스키마의 `Match(… 역사 스크립트)` — B안으로 스크립트 소비가 사라지면 문구 조정.
- **xG 표시값이 실제 축구의 약 2배**(슛당 0.20~0.25, 실제 0.10~0.12). 기획서가 xG 정확도를 주장하지 않도록 주의. 미수정 상태다.
