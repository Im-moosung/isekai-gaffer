대체역사 축구 전략 시뮬레이션

리매치: 코리아 2026

탈락한 한국을 우승까지 지휘하는 전략 시뮬레이션 — 당신의 모든 결정이 실시간으로 중계된다

데이커 월간 해커톤 · 내가 축구 감독이라면 — 월드컵 전술 웹서비스 챌린지
2026-07-24

1. 서비스 개요

  • 실제 2026 월드컵 조별리그에서 탈락한 한국을, 사용자가 감독이 되어 우승까지 끌어올리는 대체역사 전략 시뮬레이션임.
  • 실제 결과 기준점: 한국은 A조 3위(1승 2패, 승점 3)로 조별리그 탈락. 본 서비스는 이 결과를 되돌리는 것을 전제로 함.
한 줄 콘셉트: "탈락한 한국을 우승까지 지휘하는 전략 시뮬레이션 — 당신의 모든 결정이 실시간으로 중계된다."

사용자는 인트로 몽타주 종료 시점부터 대표팀 감독이 되어 조별리그 3경기부터 결승까지 라인업·전술을 직접 구성하고 경기 중 실시간 지시를 내림. 전략 시뮬레이션이 본체이며, TV 중계 연출은 그 위에 얹힌 몰입 표현 레이어임.

핵심 차별점은 관점 전환임.

  • 대부분의 축구 웹서비스는 사용자를 관전자로 둠. 본 서비스는 사용자를 터치라인의 감독으로 둠.
  • 스코어버그·티커·리플레이 등 방송 그래픽은 사용자 결정을 따라오는 출력 장치이며, 소비 콘텐츠가 아님.
  • 조작과 결과의 인과가 화면에서 즉시 드러남(예: "라인을 올렸더니 뒷공간을 내줬다"는 해설이 다음 장면에 출력).

경기 후 처리 흐름은 다음과 같음.

  • AI가 사용자의 실제 결정 로그를 근거로 기자회견 질문을 생성하고, 답변이 다음 날 신문 1면 헤드라인으로 생성됨.
  • 캠페인 종료 시 도달 라운드에 맞춰 AI가 맞춤 에필로그를 서술하고, 신문 1면 공유 카드와 익명 리더보드 등록으로 마무리됨.
  • 목표: "내가 감독이라면"이라는 상상을 실제 데이터 기반의 완주 가능한 캠페인으로 구현.

2. "감독 경험" 설계 의도

2.1 관전자가 아닌 터치라인의 감독

  • 설계 원칙: 사용자는 관전자가 아닌 터치라인의 감독이며, 방송은 사용자 결정을 따라옴.
  • 순수 관람 화면은 시작 인트로 몽타주 하나뿐이며, 스킵 가능.
  • 그 외 모든 화면에서 사용자는 선택·배치·지시를 수행함.

2.2 권한 확장 서사: 역사 수정 → 미지 개척

캠페인 진행에 따라 사용자 권한이 확대되는 서사 구조임.

  • 조별리그 (역사 구간 — 역사 수정): 실제 3경기를 재현. 전반은 실제 역사대로 압축 재생되며, 사용자는 관찰 노트 태깅의 제한적 개입만 수행. 하프타임에 전권 인수 — 팀토크·전술 재구성·교체로 후반전 지휘. "실제로 벌어진 절반" 관찰 후 "사용자가 바꾸는 절반"으로 전환되는 구조임.
  • 토너먼트 (미지 구간 — 미지 개척): 조 2위 이상 통과 시 실제 역사에 없는 영역이 열림. 킥오프부터 선발·전술 전부가 사용자 몫이며, 관찰 구간 없이 전권 지휘.
  • 진출 조건 "역사 수정 최소 조건 = 2위"가 확장 서사의 관문임. 조 3위 이하 종료 시 실제 역사대로 탈락 엔딩.
  • 실제 대회 규정은 12개 조 3위 중 상위 8팀까지 와일드카드 진출이 가능했으나, 본 게임은 진행 편의를 위해 조 1·2위만 진출하는 규칙으로 단순화함.

2.3 장르 검증 요소와 AI 개선 지점

축구 감독 시뮬레이션 장르에서 오랜 기간 검증된 감독 고유 경험을 선별 반영함.

  • 팀토크: 하프타임에 격노/격려/침착/신뢰 등 톤 선택 → 팀 상태와 맞물려 사기 변동.
  • 역할 지정: 선발 11인에 포지션별 세부 역할 부여.
  • 체력·로테이션: 토너먼트 연전에서 피로 누적, 경기 사이 체력 보고 기반 로테이션 결정.

동시에 기존 장르의 공통 한계 하나를 개선함 — 고정 선택지형 기자회견.

  • 기존 게임들의 기자회견은 고정 보기 중 택일하는 반복 작업에 가까움.
  • 본 서비스 AI 기자회견은 사용자가 해당 경기에서 실제 내린 결정 로그를 근거로 질문 생성(예: "왜 수비 라인을 끝까지 올린 채 버텼는가").
  • 매 경기 플레이에 맞춰 질문이 달라지며, 답변은 신문 1면 어록으로 기록됨.

3. 페이지 구성

  • 기본 레이아웃: 감독 콘솔(우측, 상시 개방) + 경기 뷰(좌측, 방송 스킨) 이원 구조.
  • 방송 그래픽(스코어버그·티커·리플레이 와이프·교체 그래픽)은 사용자 결정에 반응하는 출력 장치.
  • 반응형: 심사 기준을 고려해 데스크톱 우선, 모바일에서는 콘솔을 하단 시트로 전환.

4. 핵심 인터랙션 명세

  • 설계 원칙: 조작 시간 > 관전 시간.
  • 경기당 결정 포인트 8~12개, 하이라이트 순수 재생 경기당 총 3~4분으로 제한.
  • 능동 조작 시간이 수동 관전 시간보다 항상 길도록 인터랙션 배치.

인과 가시성

  • 동적 인터랙션의 증명은 조작→결과 인과의 가시성임.
  • 사용자 지시 변경은 다음 하이라이트 장면·해설 멘트에 명시적으로 반영됨.
  • 예: 수비 라인 상향 지시 → "라인을 올렸더니 뒷공간 역습을 허용했다" 해설과 함께 해당 장면 재생.
  • 결정이 화면 사건으로 되돌아오는 루프가 감독 경험의 핵심임.

5. 데이터 활용 방식

5.1 실제 2026 월드컵 데이터 기반

캠페인 사실관계는 실제 2026 월드컵 데이터에 기반함.

  • 조별리그 3경기 (역사 구간): 한국 A조 3경기를 실제 순서·결과대로 재현 — 1차전 체코전(2-1 승), 2차전 멕시코전(0-1 패), 3차전 남아공전(0-1 패). 실제 A조 3위(1승 2패, 승점 3)가 출발점.
    • 실제 순서가 게임 구조와 맞물림: 1차전은 실제 승리 경기로 승리 재현 튜토리얼, 2·3차전은 둘 다 "전반 0-0 → 후반 실점 패배"로 하프타임 개입 메커닉의 무대. 3차전 남아공전은 승리 시 16강행이었던 실제 탈락 확정 경기.
  • 토너먼트 브래킷 경로 (미지 구간): 조 1위 통과 시 각 라운드 상대는 실제 대진에서 해당 슬롯에 올라온 팀을 배치한 게임 캐논으로 확정(카운터팩추얼 — 실제 역사가 아니라 실제 대진 구조 기반 가상 경로).
    • 1위 경로(메인 캐논): 에콰도르 → 잉글랜드 → 노르웨이 → 아르헨티나 → 스페인(결승).
    • 2위 경로(하드 모드): 캐나다 → 모로코 → 프랑스 → 스페인 → 아르헨티나(결승).
    • 두 경로 모두 최종 2경기에서 실제 결승 진출 두 팀(스페인·아르헨티나)을 격파해야 하는 구조.
  • 조별 성적이 경로와 난이도 곡선을 결정. 1위 경로는 약체 에콰도르로 시작하는 상승 곡선, 2위 경로는 개최국 캐나다로 시작해 중반 프랑스가 추가되는 하드 모드.

5.2 자체 구성 더미 JSON

대회 규정 권장 방식에 따라 실제 데이터는 사실관계 뼈대로만 활용하고 나머지는 자체 구성 더미 JSON으로 채움.

  • 선수 이름·포지션·등번호·소속은 공식 스쿼드를 복수 소스로 교차 검증한 값만 사용 — 기본 정보 창작 없음.
  • 능력치는 대회 실측 활약·득점 기록·평판 등 실제 근거에 기반해 자체 산정(일관성 앵커 기준표 적용, 상용 게임 수치 미복사). 주발·포지션 적합도·세트피스 성향 포함.
  • 팀 단위 실측 스탯(점유율·패스 성공률·슈팅·파울 등 대회 평균)을 캘리브레이션 타깃으로 저장 — AI 기본 상태의 시뮬 결과가 실제 대회 평균 스탯에 수렴하도록 검증함(예: 스페인 상대 시 점유율 열세, 남아공전은 거친 파울 수치가 재현됨).
  • 대회 개막 시점 FIFA 랭킹 반영 — 난이도 티어·업셋 보너스 산정과 방송 그래픽 노출에 사용.
  • 초상권 회피를 위해 사진 미사용, 도트/이니셜로 표현.
  • 스쿼드 규모: 한국 26인 + 상대 10팀 × 18인 내외(조별 3팀 + 1위 경로 5팀 + 2위 경로 5팀, 중복 제외).
  • 데이터 스키마: Team, Player(능력치 6축·체력·사기), Match(슬롯·상대·역사 스크립트), TacticState, DecisionLog, CampaignRun.

5.3 신뢰도 검증 프로세스

  • 사실관계는 별도 리서치 문서에서 신뢰도 등급을 매겨 검증.
  • 위키피디아 및 복수 주요 미디어(CBS Sports·ESPN·FIFA·NBC) 교차 확인을 통과한 🟢 HIGH 항목만 사실로 노출.
  • 조별 3경기 스코어·득점자는 교차 검증 통과한 실제 경기 재현.
  • 브래킷 슬롯 구조와 1위/2위 경로는 검증된 실제 대진 기반이되 게임 캐논(카운터팩추얼)으로 구분 표기 — 한국이 실제와 다른 순위로 통과 시 대진 조합이 달라지므로 "실제로 벌어질 역사"로 단정하지 않음.
  • 서비스 진입부·공유 카드에 "실제 2026 월드컵을 모티브로 한 대체역사 픽션" 고지.

토너먼트 진출 규칙은 게임 편의상 단순화함 — 조 1·2위만 진출.

  • 실제 대회 규정은 12개 조 3위 중 상위 8팀까지 와일드카드 진출 가능. 본 게임은 진행 편의와 경로 명확성을 위해 조 1·2위만 진출로 단순화하고, 3위 이하는 실제 역사대로 탈락 엔딩 처리.
  • 부가 근거: A조 3위의 와일드카드 경로는 실제 미발생("3A 슬롯" 브래킷 부재)이며 FIFA 495개 조합표 의존으로 확정 불가한 🔴 미확인 항목 — 추측으로 상대를 채우지 않는 데이터 원칙과도 부합.

6. 주요 사용 흐름

  • 캠페인은 인트로 몽타주에서 시작해 역사 구간(조별리그)·미지 구간(토너먼트)을 거쳐 도달 라운드별 결말로 수렴.

데모 진입점:

  • 처음 방문한 심사자·투표자를 위해 랜딩에 정식 캠페인과 별개의 "바로 지휘하기" 데모 진입점을 둠.
  • 조별 완주·진출 조건 게이트 없이 풀 권한 토너먼트급 경기 1개를 즉시 시작, 선발·전술·상시 콘솔·경기 후 AI 기자회견까지 핵심 인터랙션을 3~5분 안에 체험(리더보드 미반영, 종료 후 정식 캠페인 유도).
  • 1차 대중투표·심사 동선을 겨냥한 장치.
  • 경기 간: 체력 보고 → 로테이션 결정(연전 피로 누적), 무승부 시 승부차기 인터랙티브 미니게임.
  • 결말: 도달 라운드별 엔딩 + AI 맞춤 에필로그 + 신문 1면 공유 카드 → 리더보드 등록(익명).
  • 조 3위 이하 종료 시 실제 역사대로 탈락 엔딩(와일드카드 경로 미사용).
  • 리더보드 점수: 최종 도달 라운드를 주축으로 승점·득실, 강팀 격파 업셋 보너스, 무실점 보너스를 합산 산출.

7. (보너스) 기술적 신뢰성

  • 동적 기능의 오류 없는 안정 작동을 완성도 핵심으로 봄. 다음 전략을 둠.
  • 결정론적 규칙 엔진: 외부 의존 없는 클라이언트 사이드 결정론 규칙 엔진으로 시뮬레이션 동작. 시드 고정 시 동일 입력이 동일 결과를 내므로 리더보드 리플레이 검증 가능. 밸런스는 시드 고정 자동 시뮬 배치(전술 조합 매트릭스 × 다회)로 사전 검증. 팀 전력은 선수 능력치 × 포지션·역할 적합도 × 전술 상성 × 체력 × 사기/모멘텀으로 분 단위 이벤트 루프에서 계산.
  • AI 폴백: AI 기능(기자회견·코치·상대 벤치 코멘트·에필로그)은 서버 보관 키를 통한 서버리스 API 프록시 경유로 경량 LLM을 호출, 심사자 별도 키 입력 불필요. 모든 AI 호출은 3초 타임아웃 시 템플릿 폴백으로 자동 전환, AI 전면 장애에도 게임 완주 가능. 남용은 익명 ID별 레이트리밋·공통 응답 캐시로 제어.
  • AI 콘텐츠 세이프가드: 생성 텍스트의 실존 인물 비하·명예훼손 방지를 위해 3단 방어 적용 — 시스템 프롬프트에 실존 인물 실명 비판·부정 평가·허위 인용 금지 제약, 출력 후처리(실명 블랙리스트 + 부정 표현 필터), 폴백 템플릿 전량 사전 검수. 상대 벤치 코멘트는 실존 감독 실명·페르소나 대신 익명 직함("상대 벤치")으로만 처리.
  • 3D 하이라이트 go/no-go 게이트: 3D 골 하이라이트는 완성도 위협 방지를 위해 게이트를 둔 부가 기능. 7/30까지 기준 시퀀스 미달 시 컷하고 2D 방송 리플레이(와이프+슬로모 오버레이)로 대체, 저사양 환경에서는 3D 끄기 토글·자동 감지 폴백 동작.
  • 저작권·상표 준수: 3D 모델(CC0)·애니메이션·사운드(CC0/상업 무료)·폰트(OFL 등 오픈 라이선스)를 라이선스 확인 범위 내에서만 사용, 에셋 라이선스 원장을 구현 내내 유지. 방송 그래픽·스코어버그는 전부 오리지널 디자인, 협회 엠블럼·FIFA/월드컵 공식 로고·트레이드드레스 미사용, 팀 식별은 국기+국가명으로만 처리. 관중음은 실존 응원가 대신 무가사 함성·창작 챈트(CC0) 사용, 신문 1면 공유 카드에 "대체역사 FICTION" 워터마크 명시. 회원가입·결제 없이 브라우저에서 바로 플레이 가능.
