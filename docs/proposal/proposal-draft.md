# 리매치: 코리아 2026

> 데이커 월간 해커톤 「내가 축구 감독이라면 — 월드컵 전술 웹서비스 챌린지」 기획서 (초안)
> 작성일: 2026-07-23

---

## 1. 서비스 개요

**실제 2026 월드컵에서 조별리그 탈락한 한국을, 당신이 감독이 되어 우승까지 끌어올리는 대체역사 전략 시뮬레이션이다.**

한 줄 콘셉트: **"탈락한 한국을 우승까지 지휘하는 전략 시뮬레이션 — 당신의 모든 결정이 실시간으로 중계된다."**

실제 2026 월드컵에서 한국은 A조 3위(1승 2패, 승점 3)로 조별리그에서 탈락했다. 「리매치: 코리아 2026」은 그 결과를 되돌린다. 사용자는 인트로 몽타주가 끝나는 순간부터 대표팀 감독이 되어, 조별리그 3경기부터 결승까지 직접 라인업을 짜고 전술을 세우며 경기 중 실시간으로 지시를 내린다. 전략 시뮬레이션이 서비스의 본체이고, TV 중계 연출은 그 위에 얹힌 몰입 표현 레이어다.

핵심 차별점은 관점의 전환이다. 대부분의 축구 웹서비스가 사용자를 "지켜보는 사람"으로 두는 반면, 이 서비스는 사용자를 **터치라인의 감독**으로 세운다. 스코어버그, 티커, 리플레이 같은 방송 그래픽은 사용자의 결정을 **따라오는 출력 장치**이지, 사용자가 소비하는 콘텐츠가 아니다. "라인을 올렸더니 뒷공간을 내줬다"는 해설이 바로 다음 장면에 흘러나오는 식으로, 조작과 결과의 인과가 화면 위에서 즉시 드러난다.

경기 후에는 AI가 사용자의 실제 결정 로그를 근거로 기자회견 질문을 던지고, 그 답변이 다음 날 신문 1면 헤드라인으로 생성된다. 캠페인이 끝나면 도달한 라운드에 맞춰 AI가 맞춤 에필로그를 서술하고, 신문 1면 공유 카드와 익명 리더보드 등록으로 마무리된다. "내가 감독이라면"이라는 보편적 상상을, 실제 데이터에 뿌리내린 완주 가능한 한 편의 캠페인으로 구현하는 것이 목표다.

## 2. "감독 경험" 설계 의도

### 2.1 시청자가 아니라 터치라인의 감독

이 서비스의 설계 원칙은 한 문장으로 요약된다. **사용자는 시청자가 아니라 터치라인의 감독이며, 방송은 사용자의 결정을 따라온다.** "보기만 하는 화면"은 시작 인트로 몽타주 단 하나뿐이며, 그마저 스킵할 수 있다. 나머지 모든 장면에서 사용자는 무언가를 선택하고 배치하고 지시한다.

### 2.2 권한이 확장되는 서사: 역사 수정 → 미지 개척

감독 경험은 캠페인이 진행될수록 사용자에게 주어지는 권한이 커지는 서사 구조를 갖는다.

- **조별리그 (역사 구간 — "역사를 수정한다")**: 실제 벌어진 3경기를 재현한다. 경기 전반전은 실제 역사대로 압축 재생되며, 사용자는 거슬리는 장면을 관찰 노트로 태깅하는 제한된 개입만 한다. 그리고 **하프타임에 전권을 인수한다.** 팀토크로 사기를 흔들고, 전술을 재구성하고, 교체 카드를 꺼내 후반전을 직접 지휘한다. 즉 "실제로 벌어진 절반"을 관찰한 뒤 "내가 바꾸는 절반"으로 넘어가는 구조다.
- **토너먼트 (미지 구간 — "미지를 개척한다")**: 조 2위 이상으로 통과하면 실제 역사에 존재하지 않는 영역이 열린다. 여기서는 **킥오프 순간부터 선발과 전술 전부가 사용자의 몫**이다. 관찰 구간 없이 처음부터 끝까지 감독이 전권을 쥔다.

"역사를 바꾸려면 최소 2위"라는 진출 조건이 이 확장 서사의 관문 역할을 한다. 조 3위 이하로 끝나면 실제 역사대로 탈락 엔딩을 맞는다.

### 2.3 FM에서 흡수한 것과, AI로 넘어서는 지점

축구 매니저 장르(FM)에서 검증된 감독 고유의 경험을 선별해 흡수한다.

- **팀토크**: 하프타임에 격노/격려/침착/신뢰 등 톤을 선택하면, 팀 상태와 맞물려 사기가 변한다.
- **역할 지정**: 선발 11인에 포지션별 세부 역할을 부여한다.
- **체력과 로테이션**: 토너먼트 연전에서 피로가 누적되며, 경기 사이 체력 보고를 보고 로테이션을 결정한다.

동시에 FM의 약점 하나를 정면으로 넘어선다. 바로 **반복되는 선택지형 기자회견**이다. FM의 기자회견은 정해진 보기 중 하나를 고르는 반복 작업에 가깝다. 이 서비스의 AI 기자회견은 **사용자가 그 경기에서 실제로 내린 결정 로그를 근거로** 질문을 생성한다. "왜 수비 라인을 끝까지 올린 채 버텼습니까?"처럼, 매번 사용자의 플레이에 맞춰 달라지는 추궁이 오고, 그 답변이 신문 1면 어록으로 남는다. 정형 선택지의 반복이 아니라, 내 판단에 대한 살아 있는 대화가 된다.

## 3. 페이지 구성

기본 레이아웃은 **감독 콘솔(우측, 상시 개방) + 경기 뷰(좌측, 방송 스킨)**의 이원 구조다. 방송 그래픽(스코어버그·티커·리플레이 와이프·교체 그래픽)은 사용자 결정에 반응하는 출력 장치로 동작한다. 반응형은 심사 기준을 고려해 데스크톱을 우선하며, 모바일에서는 콘솔을 하단 시트로 전환한다.

| 화면 | 역할 | 방송 프레임 연출 |
|---|---|---|
| 캠페인 허브 | 브래킷 현황과 다음 경기 확인, 캠페인 진행의 중심 | 대회 스튜디오 |
| 상대 분석 | 다음 상대 리포트 열람, 중점 대응 선택 | 스튜디오 분석 쇼 세그먼트 |
| 라인업 확정 | 선발 11인·역할·세트피스 키커 확정 | 방송 선발 라인업 발표 그래픽 |
| 경기 | 실시간 지휘의 중심 화면 | 라이브 중계 (스코어버그 + 감독 콘솔) |
| 하프타임 라커룸 | 팀토크와 전술 재구성 | 유일하게 "방송 밖" — 정적, 락커룸 톤 (극적 대비) |
| 경기 후 | AI 기자회견, 신문 1면 생성 | 플래시 인터뷰/기자회견 세그먼트 |
| 결말 | 도달 라운드별 엔딩과 에필로그, 공유 카드 | 신문 1면 + 다큐 에필로그 |

연출상 핵심은 **하프타임 라커룸이 유일하게 방송 밖 장면이라는 대비**다. 라이브 중계의 시끄러운 방송 톤에서 조용한 락커룸으로 전환되며, 감독이 팀을 마주하는 결정의 순간을 극적으로 분리한다.

## 4. 핵심 인터랙션 명세

설계 원칙: **조작 시간 > 관전 시간.** 경기당 결정 포인트는 8~12개, 하이라이트 순수 재생은 경기당 총 3~4분으로 제한한다. 사용자가 수동적으로 지켜보는 시간보다 능동적으로 조작하는 시간이 항상 길도록 인터랙션을 배치한다.

| 장면 | 인터랙션 (조작 동사) |
|---|---|
| 스쿼드/라인업 | 선발 11인 드래그앤드롭, 포지션별 역할 지정(2~3종), 주장·세트피스 키커 지정 |
| 전술 설정 | 포메이션 선택(5~6종), 수비 라인·압박 강도·템포 슬라이더, 공격 방향 |
| 경기 전 | 상대 리포트 열람 → 중점 대응 1~2개 선택 (경기 중 보너스로 작동) |
| 전반 (조별만) | 관찰 노트 태깅 — 거슬리는 장면에 문제 표시 (하프타임 브리핑 카드로 전환) |
| 경기 중 (상시) | 감독 콘솔 항상 개방: 지시 실시간 변경(분 단위 즉시 반영), 교체 준비→실행(3~5명), 돌발 결정 2~3회(제한시간 15~20초) |
| 하프타임 | 팀토크 톤 선택(격노/격려/침착/신뢰 × 팀 상태 → 사기 변화), 전술 재구성 |
| 승부차기 | 키커 순서 드래그 배치 + 각 키커 방향 지시, GK 다이빙 방향 지시 |
| 경기 후 | AI 기자회견 — 실제 내 결정을 근거로 한 질문에 답변 선택/입력 → 신문 1면 생성 |
| 경기 사이 | 체력·부상 보고 → 로테이션 결정, 다음 상대 리포트 |

### 인과 가시성

동적 인터랙션의 증명은 **조작이 결과로 이어지는 인과가 눈에 보이는 것**이다. 사용자의 지시 변경은 다음 하이라이트 장면과 해설 멘트에 명시적으로 반영된다. 예를 들어 수비 라인을 올리는 지시를 내리면, 곧이어 "라인을 올렸더니 뒷공간 역습을 허용했다"는 해설과 함께 그 장면이 재생된다. 내가 만든 결정이 화면 위 사건으로 되돌아오는 이 루프가 감독 경험의 핵심 감각이다.

## 5. 데이터 활용 방식

### 5.1 실제 2026 월드컵 데이터를 뼈대로

캠페인의 사실관계는 실제 2026 월드컵 데이터에 뿌리내린다.

- **조별리그 3경기 (역사 구간)**: 한국 A조 3경기를 실제 순서·결과대로 재현한다 — 1차전 체코전(2-1 승), 2차전 멕시코전(0-1 패), 3차전 남아공전(0-1 패). 실제 A조 3위(1승 2패, 승점 3) 결과가 캠페인의 출발점이다. 이 실제 순서는 게임 구조와 정확히 맞물린다: 1차전은 실제로도 이긴 경기라 승리를 재현하는 자연스러운 튜토리얼이 되고, 2·3차전은 둘 다 "전반 0-0 → 후반 실점 패배"여서 하프타임 개입으로 역사를 바꾼다는 핵심 메커닉의 무대가 된다. 특히 3차전 남아공전은 승리 시 16강행이었던 실제 탈락 확정 경기다.
- **토너먼트 브래킷 경로 (미지 구간)**: 한국이 조 1위로 통과했을 때 각 라운드에서 만나는 상대는, 실제 역사에서 그 슬롯에 올라온 팀으로 확정한다. 메인 캐논인 **1위 경로: 에콰도르 → 잉글랜드 → 노르웨이 → 아르헨티나 → 스페인(결승)**. 조 2위로 통과하면 하드 모드인 **2위 경로: 캐나다 → 모로코 → 프랑스 → 스페인 → 아르헨티나(결승)**로 갈린다. 두 경로 모두 최종 2경기에서 실제 결승 진출 두 팀(스페인·아르헨티나)을 꺾어야 하는 구조다.
- 조별 성적이 경로와 난이도 곡선을 결정한다. 1위 경로는 약체 에콰도르로 시작하는 깔끔한 상승 곡선, 2위 경로는 개최국 캐나다로 시작해 중반에 프랑스가 추가되는 하드 모드다.

### 5.2 자체 구성 더미 JSON

대회 규정이 권장하는 방식에 따라, 실제 데이터는 **사실관계의 뼈대로만** 활용하고 나머지는 전부 자체 구성 더미 JSON으로 채운다.

- 선수 이름·포지션·소속 국가는 실제를 참고하되, 능력치는 자체 설정한다.
- 초상권을 피하기 위해 사진은 사용하지 않고 도트/이니셜로 표현한다.
- 스쿼드 규모: 한국 26인 + 상대 10팀 × 18인 내외(조별 3팀 + 1위 경로 5팀 + 2위 경로 5팀, 중복 제외).
- 데이터 스키마: `Team`, `Player`(능력치 6축·체력·사기), `Match`(슬롯·상대·역사 스크립트), `TacticState`, `DecisionLog`, `CampaignRun`.

### 5.3 신뢰도 검증 프로세스

사실관계는 별도 리서치 문서에서 신뢰도 등급을 매겨 검증했다. 위키피디아와 복수 주요 미디어(CBS Sports·ESPN·FIFA·NBC)의 교차 확인을 통과한 🟢 HIGH 항목만 "실제 역사"로 게임에 노출한다. 브래킷 슬롯 구조와 1위/2위 경로는 이 교차 검증을 통과했다.

반대로, 한국이 3위(와일드카드)로 통과했을 경우의 토너먼트 경로는 교차 확인에 실패한 🔴 미확인 항목이다. 실제 대회에서 A조 3위는 최우수 3위 8팀에 들지 못해 탈락했으므로 "3A 슬롯" 자체가 브래킷에 존재하지 않으며, FIFA 495개 조합표의 해당 행을 확정하지 못했다. **추측으로 상대를 채우는 것은 금지한다.** 따라서 3위 이하 결말은 실제 역사대로 탈락 엔딩으로 처리하고, 와일드카드 경로는 사용하지 않는다.

## 6. 주요 사용 흐름

캠페인은 인트로 몽타주에서 시작해, 역사 구간(조별리그)과 미지 구간(토너먼트)을 거쳐 도달 라운드별 결말로 수렴한다.

```
🎬 인트로 몽타주 (유일한 순수 관람 장면, 스킵 가능)
   "2026년 여름, 한국은 조별리그에서 탈락했다. — 시간을 되돌린다."
   ↓
【역사 구간】 조별리그 3경기 — 실제 순서대로 재현
   1차전 체코(실제 2-1 승) → 2차전 멕시코(실제 0-1) → 3차전 남아공(실제 0-1, 탈락 확정 경기)
   · 경기 전: 상대 리포트 확인 + 중점 대응 선택
   · 전반: 실제 역사대로 압축 재생 + 관찰 노트 태깅(2~3회)
   · 하프타임: 전권 인수 — 팀토크 + 전술 재구성 + 교체
   · 후반: 상시 개입 감독 콘솔로 지휘
   ↓ (조 2위 이상만 토너먼트 진출 — "역사를 바꾸려면 최소 2위")
【미지 구간】 토너먼트 — 킥오프부터 전권 (선발·전술 전부 사용자)
   1위 경로: 에콰도르 → 잉글랜드 → 노르웨이 → 아르헨티나 → 스페인(결승)
   2위 경로: 캐나다 → 모로코 → 프랑스 → 스페인 → 아르헨티나(결승)
   · 조별 성적이 경로를 결정 (1위 = 정상 난이도 곡선, 2위 = 하드 모드)
   · 경기 간: 체력 보고 → 로테이션 결정 (연전 피로 누적)
   · 무승부 시: 승부차기 인터랙티브 미니게임
   ↓
🏆 결말: 도달 라운드별 엔딩 + AI 맞춤 에필로그 + 신문 1면 공유 카드
   → 리더보드 등록 (익명)
```

조 3위 이하로 끝나면 실제 역사대로 탈락 엔딩을 맞는다(와일드카드 경로 미사용). 리더보드 점수는 최종 도달 라운드를 주축으로, 승점·득실과 강팀 격파 업셋 보너스, 무실점 보너스를 더해 산출한다.

## 7. (보너스) 기술적 신뢰성

동적 기능이 오류 없이 안정적으로 작동하는 것을 완성도의 핵심으로 본다. 이를 위해 다음 전략을 둔다.

- **결정론적 규칙 엔진**: 시뮬레이션은 외부 의존 없는 클라이언트 사이드 결정론 규칙 엔진으로 동작한다. 시드를 고정하면 같은 입력이 항상 같은 결과를 내므로 리더보드 리플레이 검증이 가능하고, 밸런스는 시드 고정 자동 시뮬 배치(전술 조합 매트릭스 × 다회)로 사전 검증한다. 팀 전력은 선수 능력치 × 포지션·역할 적합도 × 전술 상성 × 체력 × 사기/모멘텀으로 분 단위 이벤트 루프에서 계산된다.
- **AI 폴백**: AI 기능(기자회견·코치·상대 감독 코멘트·에필로그)은 모두 서버 보관 키를 통한 Vercel API Route → Claude Haiku 경로로 호출되어 심사자가 별도 키를 넣을 필요가 없다. 모든 AI 호출은 3초 타임아웃 시 템플릿 폴백으로 자동 전환되며, AI가 전면 장애여도 게임은 끝까지 완주된다. 남용은 익명 ID별 레이트리밋과 공통 응답 캐시로 제어한다.
- **3D 하이라이트 go/no-go 게이트**: 3D 골 하이라이트는 완성도를 위협하지 않도록 게이트를 둔 부가 기능이다. 7/30까지 기준 시퀀스가 미달이면 컷하고 2D 방송 리플레이(와이프+슬로모 오버레이)로 대체하며, 저사양 환경에서는 3D 끄기 토글과 자동 감지 폴백이 동작한다.
- **저작권 준수**: 3D 모델(CC0), 애니메이션, 사운드(CC0/상업 무료)는 모두 라이선스를 확인한 범위 내에서만 사용한다. 회원가입·결제 없이 브라우저에서 바로 플레이 가능하다.
