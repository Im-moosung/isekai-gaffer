# 입장 연출 스토리보드 — 사용자 작성 (2026-08-01)

사용자가 손그림 4컷으로 준 연출 지시. 빨강/파랑 화살표는 선수 동선이다.

## 컷 1 — 입장

```
┌─────────────────────────────────────┐
│                                     │
│  ┌──────────┐   ○   ┌──────────┐   │
│  │ 상대편   │       │  태극기  │   │   ← 양 팀 국기를 피치에 펼친다
│  │  국기    │       │          │   │
│  └──────────┘       └──────────┘   │
│              심판 심판 심판           │   ← 심판 3인이 중앙에
│               ● ● ●                 │
└───────────────↑─↑───────────────────┘
                │ │
              파랑 빨강                    ← 두 팀이 터널에서 올라온다
```

- **양 팀 국기가 피치 위에 펼쳐져 있다** (현재 미구현)
- 심판 3인이 먼저 중앙에 선다
- 양 팀이 그 뒤에서 하단(터널)으로부터 올라온다

## 컷 2 — 좌우 분리

```
│              심판 심판 심판           │
│   ←───────    ● ● ●    ───────→     │
│  파랑(상대)              빨강(우리)    │
```

- 심판은 중앙에 남는다
- **양 팀이 각자 국기 쪽으로 갈라져 이동**한다

## 컷 3 — 우리 팀 클로즈업

```
┌───────────────────────────┐
│ 클로즈업                    │
│ ┌───────────┐ ┌─────────┐ │
│ │  ○        │ │ ▭▭▭▭▭  │ │   왼쪽: 포메이션 도해(11 도트)
│ │ ○  ○  ○   │ │ ▭▭▭▭▭  │ │   오른쪽: 선수 명단(행 목록)
│ │  ○  ○     │ │ ▭▭▭▭▭  │ │
│ │ ○ ○ ○  ○  │ │ ▭▭▭▭▭  │ │
│ └───────────┘ └─────────┘ │
└───────────────────────────┘
```

- 우리 팀 진영으로 카메라가 들어간다
- **포메이션 전술보드 + 선수 명단**을 나란히 띄운다
- **선수 한 명씩 하이라이트**되면서 캐스터가 소개한다

## 컷 4 — 상대 팀 클로즈업

컷 3과 같은 구성, 상대 팀 버전.

## 중계 — 입장부터 함께 나온다

> 입장 때부터 해설과 캐스터의 중계도 같이 나오면 좋겠어.
> 실제 중계화면처럼 각각 포메이션 전술보드 보면서 **선수 한명씩 하이라이트 되면서
> 캐스터가 소개**해줘.

**소개 문장 예시(사용자 제시):**
- `"골키퍼 김승규"`
- `"4명의 수비가 출전합니다. 김민재, 이한범, ~~, ~~~ 입니다."`

즉 **포지션 그룹 단위로 묶어 말하되 개별 이름을 부른다.** 하이라이트는 이름이 불릴 때
해당 도트·명단 행에 걸린다.

### 구현 시 주의

- 현행 입장은 `ENTRANCE_TOTAL_MS = 13800`(터널 1800 / 워크아웃 3600 / 정렬 900 /
  소개 5500 / 흩어짐 2000). **스토리보드는 이보다 길어질 수밖에 없다** — 22명을
  포지션 그룹으로 소개하려면 최소 20~30초가 필요하다.
  사용자가 앞서 *"천천히 여유롭게 퍼포먼스하면서"* 소개하라고 했으므로 **늘리는 방향이 맞다.**
  다만 **건너뛰기가 항상 있어야** 한다.
- **BGM M06이 13.80초로 잘려 있다**(`public/bgm/M06.mp3`). 연출이 길어지면
  M06을 루프하거나 원본(30.77s, 백업본 있음)에서 다시 자른다.
- 중계는 `commentary.ts`가 정본이다. 입장 소개 문장은 **경기 이벤트가 아니므로**
  기존 `commentateAll`(이벤트 1:1 계약) 밖에 둬야 한다.
- TTS는 화자 둘(캐스터 pitch 1.00 / 해설위원 0.75). **소개는 캐스터**가 한다.
- **국기는 쓴다.** (2026-08-01 정정 — 아래 오독 이력 참조)

## 정정: 국기 금지는 내(Advisor) 오독이었다 (2026-08-01)

이 문서 초판은 *"실제 국기 이미지를 쓰지 않는다 — 프로젝트 규칙상 공식 엠블럼·로고
금지"*라고 적었다. **틀렸다.** 설계 스펙 §9.1 원문은 정반대다:

> **협회 엠블럼·구단/대표팀 크레스트·FIFA·월드컵 공식 로고 미사용.**
> 팀 식별은 **국기(퍼블릭 도메인)** + 국가명 텍스트로만 처리
> — `docs/superpowers/specs/2026-07-23-worldcup-manager-sim-design.md:182`

금지 대상은 **협회 엠블럼·크레스트·FIFA 로고**다. 국기는 금지 목록의 반대편, 즉
**규칙이 지정한 대체 수단**이다. 두 가지를 한 덩어리로 묶은 것이 오독의 내용이다.
사용자 스토리보드에도 **"태극기"**라고 명시돼 있었다.

이 오독이 코드 두 곳에 주석으로 박혔다 — 함께 고쳐야 한다:
- `src/ui/pitch/three/entrance.ts:140-142` (`ENTRANCE_BANNER_HOME/AWAY` 팀 색 tifo)
- `src/ui/pitch/three/textures.ts:822-826` (`makeBannerCanvas`)

### 그래서 무엇을 쓰는가

- 국기 도안 자체는 저작권 대상이 아니다(각국 정부 공표 도안). **퍼블릭 도메인 SVG**를
  받아 `docs/assets-licenses.md` 원장에 출처·라이선스·확인일을 등록한다 — 새 에셋은
  전부 등록이 규칙이다(§9.1 마지막 항).
- **이모지 국기(🇰🇷)는 쓰지 마라.** `docs/research/ui-redesign.md`의 G-4·H-6이
  이미 결함으로 잡았다 — OS마다 모양이 다르고 **Windows에서 국가 코드 2글자로
  렌더된다.** 처방도 거기 적혀 있다: **SVG 스프라이트**(12개국).
- 여전히 금지: 협회 엠블럼, 대표팀 크레스트, FIFA·월드컵 공식 로고, 그 트레이드드레스.

### 반영 결과 (2026-08-01)

- 자산 `public/flags/*.svg` **12장**(캠페인 등장 12개국 전부 — `TEAM_IDS`가 정본).
  출처 lipis/flag-icons (MIT), 원장 등록 완료 → `docs/assets-licenses.md` §국기.
- 매핑·로더는 `src/ui/flags/flags.ts`. 배너 도안은 `textures.makeBannerCanvas`가
  **국기 + 하단 국가명 캡션 띠**로 그린다(§9.1의 "국기 + 국가명 텍스트").
- 배너 크기를 20×12 m(5:3) → **16×12 m(4:3)** 로 줄였다. 국기 자산이 전부 4:3이라
  면 비율을 맞춰야 도안이 늘어나지 않는다.
- SVG 디코드가 비동기라 `scene.ts`는 **폴백 도안 → 국기 교체** 2단계로 간다. 로드 실패·
  jsdom에서는 예전 팀 색 도안이 그대로 남아 연출이 멈추지 않는다.
- 실주행 캡처: `docs/audit/shots/flag-*.png` (스크립트 `tools/flag-capture/run.mjs`).
- 이모지 국기 표면 정리는 **할 것이 없었다** — `data/teams/*.json`에 `flag` 이모지
  필드가 있으나 `grep -rn '\.flag' src` 결과 소비처가 0건이다(스코어버그·상대 카드 모두
  국가명 텍스트만 쓴다). G-4·H-6의 나머지 처방은 그 표면들이 국기를 쓰기로 할 때
  같은 자산을 재사용하면 된다.
