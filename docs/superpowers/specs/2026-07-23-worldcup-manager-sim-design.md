# 설계 문서: 리매치: 코리아 2026

> 데이커 월간 해커톤 "내가 축구 감독이라면 — 월드컵 전술 웹서비스 챌린지" 참가작
> 작성일: 2026-07-23 · 상태: 사용자 승인 완료 (콘셉트/프레임/범위)

## 1. 한 줄 콘셉트

**"탈락한 한국을 우승까지 지휘하는 전략 시뮬레이션 — 당신의 모든 결정이 실시간으로 중계된다."**

실제 2026 월드컵에서 조별리그 탈락(A조 3위, 1승 2패)한 한국 대표팀을, 사용자가 감독이 되어 조별리그부터 결승까지 지휘하는 대체역사 캠페인. 전략 시뮬레이션이 본체, TV 중계 연출은 몰입을 위한 표현 레이어다. **사용자는 시청자가 아니라 터치라인의 감독이며, 방송은 사용자의 결정을 따라온다.**

## 2. 평가 기준 매핑 (설계 근거)

| 평가 항목 (배점) | 이 설계의 대응 |
|---|---|
| 참신성 (30) | 대체역사 캠페인 서사, AI 기자회견, "내 결정이 중계되는" 프레임 — 전술보드 클론과 차별화 |
| 감독 경험 설계 (25) | 상시 개입 감독 콘솔, 결정 밀도 8~12개/경기, 팀토크·로테이션·승부차기 등 감독 고유 경험 |
| 완성도 (25) | 결정론적 규칙 엔진(제로 외부 의존), AI 템플릿 폴백, 3D go/no-go 게이트, 2D 우선 |
| 기획/구현 완성도 (20) | "내가 감독이라면"이라는 보편 감정 → 조별(역사 수정)→토너먼트(미지 개척)의 권한 확장 구조로 일관 구현 |

1차 대중투표 대응: 한국 팀 우승 서사(감정 동원) + 공유 카드(신문 1면) + 3분 안에 재미(빠른 온보딩).

## 3. 캠페인 구조 (유저 저니)

```
🎬 인트로 몽타주 (유일한 순수 관람 장면, 스킵 가능)
   "2026년 여름, 한국은 조별리그에서 탈락했다. — 시간을 되돌린다."
   ↓
【역사 구간】 조별리그 3경기 — 실제 경기 재현 (실제 순서)
   1차전 체코(실제 2-1 승, 승리 재현 = 튜토리얼) → 2차전 멕시코(실제 0-1 패)
   → 3차전 남아공(실제 0-1 패, 탈락 확정 경기 — 최대 스테이크)
   ※ 2·3차전 모두 "전반 0-0 → 후반 실점"이라 하프타임 개입 메커닉과 정확히 부합
   · 경기 전: 상대 리포트 확인 + 중점 대응 선택
   · 전반: 실제 역사대로 압축 재생 + 관찰 노트 태깅(2~3회)
   · 하프타임: 전권 인수 — 팀토크 + 전술 재구성 + 교체
   · 후반: 상시 개입 감독 콘솔로 지휘
   ↓ (조 2위 이상만 토너먼트 진출 — "역사를 바꾸려면 최소 2위")
【미지 구간】 토너먼트 — 킥오프부터 전권 (선발·전술 전부 사용자)
   1위 경로: 에콰도르 → 잉글랜드 → 노르웨이 → 아르헨티나 → 스페인(결승)
   2위 경로: 캐나다 → 모로코 → 프랑스 → 스페인 → 아르헨티나(결승)
   · 조별 성적이 경로를 결정 (1위 = 정상 난이도 곡선, 2위 = 하드 모드)
   · 경기 간: 체력 보고 → 로테이션 결정 (연전 피로 누적)
   · 무승부 시: 승부차기 인터랙티브 미니게임
   ↓
🏆 결말: 도달 라운드별 엔딩 + AI 맞춤 에필로그 + 신문 1면 공유 카드
   → 리더보드 등록 (익명)
```

- **진출 규칙(게임 단순화, 사용자 확정 2026-07-24)**: 실제 대회는 12개 조 3위 중 상위 8팀도 진출 가능하나, 게임은 진행 편의상 **조 1·2위만 진출**. 조 3위 이하 = 실제 역사 반복(탈락) 엔딩 (부가 근거: A조 3위 와일드카드 경로는 실제 미발생·확정 불가 — docs/research/2026-bracket-paths.md §4)
- **프레이밍**: 조별 3경기는 교차검증된 실제 스코어를 쓰는 **"실제 경기 재현"**, 토너먼트 경로는 "실제 대진 슬롯에 올라온 팀"을 배치한 **"게임 캐논"**(카운터팩추얼, 실제 역사 아님). 데이터 사실관계는 research 문서 신뢰도 🟢 항목만 사용하고, 미확인 세부는 자체 구성 더미로 대체
- **오인 방지 고지**: 서비스 진입부와 공유 카드에 "실제 2026 월드컵을 모티브로 한 **대체역사 픽션**"임을 명시

### 3.1 "바로 지휘하기" 데모 모드 (심사자 3분 온보딩)

처음 온 심사자·투표자가 게이트(조별 완주 + 조 2위 이상) 없이 핵심 경험에 즉시 도달하도록, 랜딩에서 진입하는 별도 데모 진입점을 둔다.

- 랜딩에서 **풀 권한 토너먼트급 경기 1개를 즉시 시작**(킥오프부터 선발·전술 전권)
- 경기 → 경기 후 **AI 기자회견까지 3~5분** 안에 핵심 인터랙션 일순 체험
- 리더보드 미반영(정식 캠페인과 분리), 종료 후 정식 캠페인으로 유도

## 4. 핵심 인터랙션 명세 (결정 밀도)

원칙: **조작 시간 > 관전 시간.** 경기당 결정 포인트 8~12개, 하이라이트 순수 재생 총 3~4분. "보기만 하는 화면"은 인트로 하나뿐.

| 장면 | 인터랙션 (조작 동사) |
|---|---|
| 스쿼드/라인업 | 선발 11인 드래그앤드롭, 포지션별 역할 지정(2~3종), 주장·세트피스 키커 지정 |
| 전술 설정 | 포메이션 선택(5~6종), 수비 라인·압박 강도·템포 슬라이더, 공격 방향 |
| 경기 전 | 상대 리포트 열람 → 중점 대응 1~2개 선택(경기 중 보너스로 작동) |
| 전반(조별만) | 관찰 노트 태깅 — 거슬리는 장면에 문제 표시(하프타임 브리핑 카드로 전환) |
| 경기 중 (상시) | 감독 콘솔 항상 개방: 지시 실시간 변경(분 단위 즉시 반영), 교체 준비→실행(3~5명), 돌발 결정 2~3회(제한시간 15~20초) |
| 하프타임 | 팀토크 톤 선택(격노/격려/침착/신뢰 × 팀 상태 → 사기 변화), 전술 재구성 |
| 승부차기 | 키커 순서 드래그 배치 + 각 키커 방향 지시, GK 다이빙 방향 지시 |
| 경기 후 | AI 기자회견 — 실제 내 결정을 근거로 한 질문에 답변 선택/입력 → 신문 1면 생성 |
| 경기 사이 | 체력·부상 보고 → 로테이션 결정, 다음 상대 리포트 |

인과 가시성: 지시 변경은 다음 하이라이트 장면과 해설 멘트에 명시적으로 반영된다("라인을 올렸더니 뒷공간 역습 허용"). 조작→결과의 인과가 보이는 것이 동적 인터랙션의 증명.

위 인터랙션 대부분(전권 라인업·전술·상시 콘솔·AI 기자회견)은 §3.1 "바로 지휘하기" 데모 모드에서 게이트 없이 3~5분 안에 노출되어, 심사자가 첫 진입에서 핵심 조작을 직접 체험한다.

## 5. 화면 구성

기본 레이아웃: **감독 콘솔(우측, 상시) + 경기 뷰(좌측, 방송 스킨)**. 방송 그래픽(스코어버그·티커·리플레이 와이프·교체 그래픽)은 사용자 결정에 반응하는 출력 장치다.

| 화면 | 방송 프레임 연출 |
|---|---|
| 캠페인 허브 | 대회 스튜디오 — 브래킷 현황, 다음 경기 |
| 상대 분석 | 스튜디오 분석 쇼 세그먼트 |
| 라인업 확정 | 방송 선발 라인업 발표 그래픽 |
| 경기 | 라이브 중계 (스코어버그 + 감독 콘솔) |
| 하프타임 라커룸 | 유일하게 "방송 밖" — 정적, 락커룸 톤 (극적 대비) |
| 경기 후 | 플래시 인터뷰/기자회견 세그먼트 |
| 결말 | 신문 1면 + 다큐 에필로그 |

반응형: 데스크톱 우선(심사 기준), 모바일은 콘솔을 하단 시트로 전환.

## 6. 시뮬레이션 엔진

- **클라이언트 사이드 결정론적 규칙 엔진** (시드 고정 → 같은 입력 = 같은 결과, 대결·리더보드 검증 가능, 외부 의존 0)
- 분 단위 이벤트 루프: 팀 전력 = 선수 능력치 × 포지션·역할 적합도 × 전술 상성 행렬(포메이션 매치업 + 지시 조합) × 체력 × 사기/모멘텀
- 사용자 지시 변경은 다음 분부터 확률 테이블에 반영
- 난이도 축: 상대 전력(라운드 상승) + 상대 감독 AI의 카운터 전술 빈도·정확도 + 캠페인 누적 체력
- 출력: 하이라이트 이벤트 목록(유형/선수/좌표/결과) → 2D 방송 뷰가 렌더, 3D(게이트 통과 시)가 골 장면 렌더
- 엔딩 분기: 대승/신승/역전/승부차기 등 결과 다양성 + 라운드별 엔딩

### 6.1 선수 개인 모델 (전술만이 아니라 "누구를 어디에 쓰는가"가 결과를 가른다)

**능력치 축** — 필드 플레이어 6축 + GK 전용 3축:
- 필드: 슈팅 / 패스 / 드리블 / 수비(태클·인터셉트) / 피지컬 / 스피드 (각 1~99)
- GK: 선방 / 공중볼 / 빌드업. GK 포지션에 필드 플레이어 배치 시 파국적 페널티
- 부가 속성: **주발(왼발/오른발/양발)**, 세트피스 적합도, 승부차기 성향, 스태미나(체력 소모율), 사기

**포지션 적합도 커브** — 선수마다 포지션별 계수를 갖는다:
- 주 포지션 1.0 / 인접 포지션(예: RW→ST) 0.85 / 비인접(예: 윙어→풀백) 0.65 / 극단 미스매치(공격수→CB) 0.4
- 미스매치는 능력치 감쇠에 그치지 않고 **해당 포지션의 책임 이벤트에서 실수 확률이 추가 상승** (공격수를 CB에 두면 대인 방어 이벤트에서 태클 실패·파울 확률 증가) — "메시를 수비수로 쓰면 전술이 아무리 좋아도 마이너스"를 구조로 보장
- UI: 미스매치 배치 시 전술 보드에 즉시 경고 표시 (적합도 색상: 초록/노랑/빨강)

**주발 효과**:
- 윙 배치 × 주발 상호작용: 동측 배치(오른발-오른쪽 윙) = 크로스·돌파 보너스, 역측 배치(왼발-오른쪽 윙) = 컷인 슈팅 보너스·크로스 페널티 — "인버티드 윙어"가 전술 선택지가 됨
- 세트피스 키커 지정·승부차기 방향 경향에 반영

**이벤트 단위 스탯 대결** — 팀 전력 스칼라가 아니라, 매 하이라이트 이벤트마다 관련 개인 스탯이 직접 대결한다:
- 슛 이벤트 = 슈터의 슈팅 (×포지션 적합도 ×체력) vs GK 선방 / 돌파 = 드리블+스피드 vs 수비수의 수비+스피드 / 전개 = 패스 vs 상대 압박 강도
- 이벤트 참여자는 포지션·역할·전술 지시 기반 가중 추첨 → 손흥민을 최전방에 두면 손흥민의 슈팅으로 골이 나는 서사가 자연히 만들어짐
- 하이라이트·해설 텍스트에 개인 스탯의 인과가 노출("지친 김민재가 한 발 늦었습니다")

**교체 판단 정보** — 감독 콘솔의 선수 카드에 6축 스탯·주발·체력·사기 게이지를 상시 표시, 교체 패널은 체력순/스탯순 정렬 지원. 개인 스탯이 "보이는 참고 정보"이자 "실제 결과 변수"가 되게 한다.

### 6.2 국가별 전술 아이덴티티 (TeamProfile)

상대 팀은 능력치 목록이 아니라 **전술 정체성**을 가진다. 팀 JSON마다:
- `preferredFormations`: 시그니처 포메이션 1~2개 (실제 대회에서 쓴 포메이션 참고)
- `styleAxes`: 점유↔역습 / 압박 강도 / 라인 높이 / 템포 — 4축 성향값
- `signatureXI`: 시그니처 선발 구성 + `keyPlayers`(의존도 가중치 — 키 플레이어 봉쇄 시 팀 전력 추가 하락)
- `benchPattern`: 교체 성향 (리드 시 수비 강화형 / 추격 시 공격 올인형 등)

상대 감독 AI는 이 프로필로 시작하고, 인게임 카운터 전술도 **프로필 범위 안에서만** 선택한다 → 스페인은 끝까지 점유를 고집하고, 역습 팀은 리드하면 내려앉는 실제감. 상대 분석 리포트(워룸)에 이 프로필이 노출되어 "상대 성향을 읽고 맞춤 대응"이라는 전술 재미의 근거가 된다.

**밸런스 원칙**: 능력치·프로필은 자체 설정 더미 데이터지만 실제 선수·팀의 공개적 인상에 기반해 상식적으로 설정하고, 실존 선수를 조롱 수준으로 낮게 설정하지 않는다(§7.1 세이프가드와 일관).

## 7. AI 레이어 (물리는 규칙이, 서사는 AI가)

| 기능 | 내용 | 폴백 |
|---|---|---|
| AI 기자회견 | 경기 후 내 결정 로그 기반 추궁 질문 → 답변 → 다음 날 신문 1면(헤드라인+기사+어록) 생성 | 템플릿 질문·헤드라인 |
| AI 코치 | 경기 중 조언("측면이 뚫리고 있습니다") | 규칙 기반 트리거 문구 |
| AI 상대 벤치 코멘트 | 규칙 엔진이 고른 카운터 전술에 대한 익명 "상대 벤치" 코멘트 (직함만, 실존 감독 실명·페르소나 금지) | 정형 문구 |
| 맞춤 에필로그 | 캠페인 결정 로그 기반 다큐식 서술 | 템플릿 조합 |

- 호출 경로: Vercel API Route(키 서버 보관, **프로바이더 중립 — 환경변수로 전환**) → 경량 LLM. 심사자는 키 불필요 (규정 충족)
- 기본 프로바이더는 Phase 3 착수 시 벤치마크로 확정 (후보: Gemini Flash 계열 / Claude Haiku / Groq 오픈 모델 — 기준: 한국어 기자회견 질문 품질, 지연, 실비용, 무료 쿼터). 차점 프로바이더를 폴백 체인 2차로 배치 (1차 장애 → 2차 → 템플릿)
- 모든 AI 기능 3초 타임아웃 → 템플릿 폴백 자동 전환. AI 전면 장애에도 게임 완주 가능
- 폴백 품질 기준: 템플릿은 "AI처럼 읽히는" 다변형(조건·결정 로그에 따라 문장 분기)으로 작성해, 폴백 발동 시에도 정형 반복으로 보이지 않게 함. 심사 기간 시작 전 주요 시나리오 응답을 캐시 워밍
- 남용 제어: 익명 ID별 레이트리밋 + 공통 응답 캐시

### 7.1 콘텐츠 세이프가드 (실존 인물 보호 — 규정: 특정 선수·팀·국가 비하/명예훼손 금지)

AI 생성 텍스트(기자회견·해설·상대 벤치 코멘트·신문 1면·에필로그)는 실존 인물·팀을 대상으로 하므로 3단 방어를 둔다.

- **(a) 시스템 프롬프트 제약**: 실존 인물(감독·선수) 실명 비판, 부정 평가, 하지 않은 발언의 허위 인용을 금지. 상대 벤치는 실명·실존 감독 페르소나 대신 익명 직함("상대 벤치")으로만 지칭.
- **(b) 출력 후처리**: 실존 인물 실명 블랙리스트 + 부정 표현 필터로 생성 텍스트를 스캔, 저촉 시 폴백 템플릿으로 대체.
- **(c) 폴백 템플릿 사전 검수**: 모든 폴백 문구는 사람이 사전 검수해 비하·명예훼손 소지를 제거한 것만 번들.

## 9. 사운드

- 관중음(함성/탄식/무가사 응원 함성·창작 챈트 루프), 휘슬, 골 폭발음 — CC0 음원. 식별 가능한 실존 응원가는 저작권 문제로 사용하지 않음
- **TTS 아나운서**: ① 빌드 타임 사전 생성(선수 골 콜, 정형 멘트 → 정적 파일 번들, 지연·장애 0) — 이것이 기본 ② 동적 문장 TTS(Web Speech API)는 **부가 기능(있으면 좋음)**으로 강등 — 브라우저 지원 편차(Safari/Firefox)로 코어 경험에서 제외, 미지원 시 자동 생략 ③ 전체 음소거 토글
- 라이선스: 모든 음원 CC0/상업 무료 확인 후 사용 (규정: 저작권 준수)

### 9.1 에셋·브랜딩 가이드라인 (저작권·상표 방어)

방송 스킨이 서비스 정체성이므로, 실존 상표·트레이드드레스와의 충돌을 원천 차단한다.

- **방송 그래픽·스코어버그·티커·교체 그래픽은 전부 오리지널 디자인.** FIFA/월드컵 공식 중계 그래픽의 트레이드드레스를 모방하지 않음
- **협회 엠블럼·구단/대표팀 크레스트·FIFA·월드컵 공식 로고 미사용.** 팀 식별은 **국기(퍼블릭 도메인)** + 국가명 텍스트로만 처리
- **폰트는 OFL 등 오픈 라이선스만** (예: Pretendard). 무단 웹폰트 금지
- **3D 모델·애니메이션·음원은 CC0/상업 무료 확인 범위 내에서만** (Quaternius/Kenney, Mixamo 약관 확인)
- **신문 1면 공유 카드에 "대체역사 FICTION" 워터마크** 명시 — 실제 보도로 오인·허위사실 유포 방지
- **에셋 라이선스 원장**을 `docs/assets-licenses.md`로 구현 내내 유지(파일-라이선스-출처 URL). 수상 시 스폰서 5년 비독점 라이선스 조항까지 커버되는 재배포 가능 라이선스만 채택
