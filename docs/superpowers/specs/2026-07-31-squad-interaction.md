# 선수 조작 언어 — 워룸·작전판 공통 규약

작성 2026-07-31. 사용자 지시로 확정. **워룸(킥오프 전)과 작전판(경기 중)이 같은 규약을 쓴다** —
두 화면이 각자 다른 조작을 만들면 유저가 두 번 배워야 한다.

## 조작표

| 조작 | 결과 |
|---|---|
| 드래그앤드롭 | 즉시 실행 (교체 / 자리 바꾸기) |
| 선수 1명 클릭 | 선수 상세 |
| **선수 2명 클릭** | **나란히 비교** + 실행 버튼 활성화 |
| 실행 버튼 클릭 | 확정 |

## 실행 버튼 — 선택 조합이 라벨과 동작을 정한다

| 선택 | 버튼 | 동작 |
|---|---|---|
| 선발 + 선발 | `자리 바꾸기` | 두 슬롯 교환. 교체 횟수 미소모 |
| 선발 + 벤치 | `교체하기` | 실제 교체. **교체 인원·기회 차감** |
| 벤치 + 벤치 | 비활성 | 뛰지 않는 둘을 바꿀 이유가 없다 |

정지 선수(출장정지)는 어느 경우에도 선택 불가.

## 왜 버튼을 두는가 — 접근성

사용자 지시(2026-07-31):
> 드로그앤드랍 과 "교체하기" 버튼을 둬서 2명 선택시에만 활성화 되게 하고 교체하기 버튼
> 클릭까지 교체 할수 있도록해줘. 그러면 키보드 도 되잖아?

드래그앤드롭만 두면 키보드·터치 사용자가 교체를 못 한다(저장소에 `onKeyDown` 핸들러가 0개였다).
버튼 경로가 **접근성 우회로가 아니라 정규 경로**다 — 마우스 사용자도 비교를 보고 버튼을 누르는
쪽이 자연스럽다. 숨긴 대체 경로를 따로 만들 필요가 없어진다.

## 클릭이 교체를 하지 않는다

사용자 지시:
> 교체를 지금은 클릭 to 클릭으로 교체가 진행되는데 명확하게 드래그앤 드롭으로만 교체 되게 해줘.
> 클릭만하면 그냥 선수 상세 정보만 나오게.

즉 **클릭 → 클릭으로 교체가 성사되면 안 된다.** 클릭은 정보를 여는 동작이고, 교체는
드래그앤드롭이거나 명시적 버튼이다. 실수로 교체되는 경로를 없애는 것이 목적이다.

## 비교 뷰

2명 선택 시 뜬다. 능력치·체력·사기·경고·이 경기 기록을 **나란히** 놓고 차이가 읽히게 한다.
"잘 보이게 디자인" 지시가 있었으므로 표를 그냥 두 벌 늘어놓지 말고 **차이를 강조**하라.
