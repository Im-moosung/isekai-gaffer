# 2026 FIFA 월드컵 넉아웃 브래킷 & 한국 경로 (해커톤 게임 캐논)

> **용도**: "내가 감독이라면" 시뮬레이터. 유저가 한국(A조)을 조별리그부터 우승까지 이끈다.
> 실제 역사에서 한국은 A조 3위(1승 2패, 승점 3)로 탈락했다. 이 문서는 한국이 A조 **1위 / 2위 / 3위(와일드카드)** 로 통과했을 때, 각 라운드에서 **"그 슬롯에 실제로 올라온 팀"** 을 확정한다.
> **조사일**: 2026-07-23 / **자매 문서**: `2026-worldcup-facts.md` (대회 사실·스쿼드·시나리오). 중복 최소화 — 여기서는 브래킷 구조와 경로에 집중.

## ⚠️ 신뢰도 규칙 (자매 문서와 동일)

- 🟢 **HIGH** — 위키피디아 + 복수 주요 미디어 교차 확인.
- 🟡 **MEDIUM** — 단일 계열 소스 또는 세부 미확인.
- 🔴 **LOW / 미확인** — 소스 충돌 또는 확인 불가. 게임에 사실로 노출 금지.

이 문서의 **브래킷 슬롯 구조와 1위/2위 경로는 🟢 HIGH** (위키피디아 넉아웃/R32 문서 + CBS Sports 브래킷 + ESPN/FIFA/NBC 교차). **3위(와일드카드) 경로는 🔴 미확인** — 이유는 §4에 명시. 추측으로 채우지 않았다.

## 1. 브래킷 슬롯 배정 규칙 (48개국 포맷) 🟢 HIGH

- 32강 진출 = **12개 조 1위(12) + 12개 조 2위(12) + 최우수 3위 8개 팀(8)**.
- 3위 8팀은 **조 1위 8팀과 대진**되며, 어느 1위와 붙을지는 **"어느 조들의 3위가 통과했는가"** 조합(FIFA가 사전 공개한 495개 경우의 수)에 따라 결정된다.

## 4. 3위(와일드카드) 경로가 미확인인 이유 🔴

- 실제 대회에서 **A조 3위(한국)는 최우수 3위 8팀에 들지 못해 탈락** → "3A 슬롯"이 브래킷에 **실존하지 않음**.
- 만약 한국이 최우수 3위로 통과했다면 통과 조합이 바뀌어(실제 옵션 #67이 아닌 다른 옵션 적용), 3A가 **어느 조 1위와 붙는지는 FIFA 495개 조합표의 해당 행에 따라 달라진다**. 그 행을 이번 조사에서 **교차 확인하지 못함**.
- 구조적 사실만 확정 가능: 3위 팀은 **조 1위 8팀 중 하나**와 붙으며, 자기 조(A) 1위와는 붙지 않는다. 실제로 3위와 붙은 1위 슬롯은 {A, B, D, E, G, I, K, L}이었다.
- 한 소스(위키 조합표 자동요약)는 "3A → 1B(스위스)" 패턴을 시사했으나 **단일·자동요약이라 🔴 미확인**. 사실로 박지 말 것.
- **권장**: 3위 경로가 필요하면 게임 디자인상 "가장 가벼운 대안 루트"로 별도 창작하거나, 3위 통과 자체를 특별 이벤트로 처리. FIFA 공식 조합표 원문(하단 출처)에서 A조 포함 조합 행을 직접 확인하기 전에는 상대를 확정 표기 금지.

## 5. 게임 캐논 추천

**1위 경로를 메인 캐논으로 추천.** 근거:
1. **깔끔한 난이도 상승 곡선**: 에콰도르(약체) → 잉글랜드(강호) → 노르웨이(다크호스) → 아르헨티나(준우승) → 스페인(우승). 마지막 두 경기가 실제 결승 두 팀 = 클라이맥스가 자연스럽게 최고조.
2. **서사**: A조 실제 3위 탈락 팀이 "조 1위"로 반전하는 오버어치브 스토리가 감독 시뮬레이터에 가장 강렬.
3. 오프너(에콰도르)가 진짜 3위 약체라 초반 진입장벽이 낮아 온보딩에 유리.

2위 경로는 **하드/얼터너티브 모드**로 병행 추천(오프너 개최국 캐나다 + 8강 프랑스로 중반 난이도가 더 높고, 4강에서 우승팀 스페인을 먼저 만남).
