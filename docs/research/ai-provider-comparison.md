### 무료 티어 (AI Studio)
- **공식 docs 확인 결과:** 레이트리밋 페이지는 정확한 RPM/RPD 수치를 표로 제공하지 않고 "AI Studio 대시보드에서 확인"하도록 안내함 → **정확한 무료 티어 RPM/RPD는 공식 문서상 미확인.**
- 확인된 공식 사실: **Flash / Flash-Lite만 무료 티어 이용 가능, Pro 계열은 2026-04-01부터 유료 전용.**
- 참고(3rd-party 보고값, 공식 미확인): Flash 10 RPM / 250 RPD, Flash-Lite 15 RPM / 1,000 RPD, 공통 250k TPM 수준으로 보고됨. **프로덕션 판단 시 반드시 AI Studio 대시보드에서 실값 확인 필요.**

## 2. Anthropic API — 라인업 & 가격 (공식 페이지 확인)

100만 토큰당 가격 (USD, 표준):

| 모델 | 입력 | 출력 | 5분 캐시 쓰기 | 캐시 읽기(히트) | Batch 입력/출력 |
|---|---|---|---|---|---|
| **Claude Haiku 4.5** | **$1.00** | **$5.00** | $1.25 | $0.10 | $0.50 / $2.50 |
| Claude Haiku 3.5 (retired*) | $0.80 | $4.00 | $1.00 | $0.08 | $0.40 / $2.00 |
| Claude Sonnet 4.6 | $3.00 | $15.00 | $3.75 | $0.30 | $1.50 / $7.50 |
| Claude Sonnet 5 (~2026-08-31 도입가) | $2.00 | $10.00 | $2.50 | $0.20 | $1.00 / $5.00 |
| Claude Opus 4.8 | $5.00 | $25.00 | $6.25 | $0.50 | $2.50 / $12.50 |

\* Haiku 3.5는 Bedrock/Google Cloud 외 retired. 1st-party API 경량 모델은 사실상 **Haiku 4.5**가 현행 최경량.

- **경량 모델 현행가: Claude Haiku 4.5 = $1 입력 / $5 출력.**
- **프롬프트 캐싱:** 캐시 읽기 = 표준 입력가의 0.1배 (Haiku 4.5 기준 $0.10/MTok). 5분 쓰기 1.25배, 1시간 쓰기 2배. → 시스템 프롬프트/공통 지시문이 반복되면 캐시 히트로 입력 비용 대폭 절감.
- **Batch:** 입력/출력 모두 50% 할인 (Haiku 4.5 $0.50/$2.50). 단 24시간 비동기이므로 실시간 UX엔 부적합.
- **무료 티어:** 상시 무료 티어 없음. 공식 FAQ상 "신규 유저에게 소액의 무료 크레딧" 제공만 명시. → 지속적 무료 사용 불가.

## 3. 성능 (지연 / 스루풋 / 한국어 품질)

출처: Artificial Analysis (3rd-party 독립 벤치마크, 2026-07 기준). 공식 수치가 아니므로 참고용.

| 모델 | TTFT (초) | 출력 스루풋 (tok/s) | 지능 지수(참고) |
|---|---|---|---|
| Gemini 2.5 Flash-Lite | ~0.34~0.35 | ~213~463 | (경량) |
| Gemini 2.5 Flash | ~0.52 | ~204~206 | 14 (추정) |
| Claude Haiku 4.5 (Vertex) | ~0.59~0.92 | ~97 | 24 (추정) |

- **지연:** 세 모델 모두 TTFT는 1초 미만 → **3초 폴백 타임아웃 여유롭게 충족.** 단 출력이 400토큰에 가까울 때 Haiku 4.5(~97 tok/s)는 생성에 ~3초 이상 소요 가능 → **스트리밍 미적용 시 폴백에 걸릴 위험.** Gemini Flash 계열(200+ tok/s)은 400토큰도 ~2초 내 완료로 여유.
- **한국어 생성 품질:** 이 두 모델의 한국어 전용 정량 벤치마크(LogicKor/Ko-H5 등에서의 직접 대조 점수)는 **공식·독립 자료 모두에서 확정값 미확인.** 정성 보고: Artificial Analysis 지능 지수에서 Haiku 4.5가 Gemini 2.5 Flash보다 높게 평가됨(24 vs 14, 추정), 번역/자연스러운 문장 시나리오에서 Haiku 4.5가 좋다는 언급 존재. 다만 짧은 서사 생성용 한국어 품질은 **실제 프롬프트로 A/B 테스트 권장** (수치 근거 미확인).

## 4. 참고 대안 — Groq 무료 티어 (3rd-party 보고, 공식 미교차확인)

- 오픈소스 모델만 제공: Llama 3.1 8B, Llama 3.3 70B, GPT-OSS 120B 등.
- 무료 티어 한도(보고값): 조직 단위 30 RPM / 6,000 TPM / 14,400 RPD (모델별 상이, 예: llama-3.3-70b-versatile 30 RPM·12K TPM·1K RPD). 신용카드 불필요.
- Developer 티어(카드 등록, 무료)로 한도 10배 + 토큰비 25% 할인.
- 초고속 추론(수백 tok/s)이 강점 → 지연 민감 UX에 유리. 단 **한국어 품질은 오픈모델 특성상 상용 모델 대비 편차 큼, 검증 필요.** 해커톤 무료 프로토타입엔 매력적.

## 추천 (유스케이스 관점, 3줄)

1. **1순위 유료 = Gemini 2.5 Flash-Lite.** TTFT ~0.35s·스루풋 200+ tok/s로 3초 폴백을 확실히 지키면서 1,000캠페인 $2.34로 최저가 — 짧은 한국어 서사 생성에 과충분.
2. **품질 우선이면 Claude Haiku 4.5.** 지능 지수·자연스러운 문장에서 우위 보고, 프롬프트 캐싱으로 반복 시스템 프롬프트 비용 절감 가능. 단 출력 400토큰 시 ~3초로 폴백 경계 → **스트리밍 필수**. 비용은 Flash-Lite의 약 10배지만 1,000캠페인 $27로 여전히 저렴.
3. **해커톤 프로토타입은 Groq 무료 티어 또는 Gemini 무료 티어(Flash-Lite 15 RPM/보고값)로 시작**, 정식 배포 시 Gemini 2.5 Flash-Lite 유료로 전환. 한국어 품질은 세 후보 모두 실제 프롬프트 A/B 필수(정량 벤치 미확인).

_주의: Gemini 무료 티어 RPM/RPD, 한국어 정량 품질 점수, Groq 한도는 공식 페이지에서 확정 수치 미확인(3rd-party 보고값) — 프로덕션 결정 전 AI Studio 대시보드·실제 테스트로 검증할 것._
