# 3D 경기 화면 절차 생성 참조 이미지

이 디렉터리의 이미지는 게임에 직접 넣는 에셋이 아니다. three.js 기본 지오메트리와
CanvasTexture로 경기 화면을 절차 생성할 때의 실루엣, 색면, 킷 대비, 경기장 요소 표현을
정하는 시각 참조다.

- 생성 방식: Codex 내장 `imagegen`
- 스타일 목표: 로우폴리, 큰 색면, 적은 재질, 코드로 재현 가능한 단순 형상
- 인물 원칙: 완전히 가상의 익명 캐릭터, 단순화된 얼굴, 실존 인물 닮은꼴 금지
- IP 원칙: 실존 구단·국가대표 킷, 엠블럼, 스폰서, FIFA/월드컵 로고, 실존 상표 미사용
- 런타임 반영: 없음. `src/`와 `public/`은 이 작업에서 수정하지 않았다.

## 40–52px 판정 결론

| 항목 | 결과 | 해석 |
|---|---|---|
| 팀 구분 | 네 조합 모두 통과 | 따뜻한 스칼렛과 차가운 애저의 색상 간격이 충분하다. |
| 실루엣 | 네 조합 모두 통과 | 넓은 어깨, 몸통에서 떨어진 팔, 벌어진 두 다리, 큰 부츠가 40px 부근에서도 남는다. |
| 번호 | 44px 정면에서 읽힘, 52px에서 안정적 | 측면 번호는 카메라 각도에 따라 사라지므로 팀 구분을 번호에 의존하면 안 된다. |
| 패턴 | 무지·횡스트라이프·새시 모두 통과 | 무지가 팀 색 면적은 가장 크고, 횡스트라이프는 가장 강한 패턴 신호, 새시는 그 중간이다. |
| 얼굴·외모 계열 | 축소 시 구분되지 않음 | 이 크기에서는 실루엣·팀 색·킷만 읽혀야 하므로 의도에 맞는다. |

재생성 기준이었던 팀 색 또는 실루엣 소실은 관찰되지 않아 대비 보정 재생성은 하지 않았다.

## 킷 색 대비 권고

### 권장 팔레트

| 용도 | 빨강 팀 | 파랑 팀 |
|---|---|---|
| 주 상의·양말 | 스칼렛 `#F2383D` | 애저 `#147DF5` |
| 칼라·소매·패턴 | 버건디 `#7A1424` | 딥 네이비 `#071C4A` |
| 번호 | 아이보리 `#FFF1D0` | 흰색 `#FFFFFF` |
| 반바지 | 차콜 `#1B1F2A` | 딥 네이비 `#071C4A` |

위 HEX는 조명을 입힌 생성 이미지에서 다시 추출한 값이 아니라, 절차 생성 코드에서 사용할
권장 베이스 컬러(albedo) 목표값이다.

- 빨강은 자주색으로 기울지 않는 따뜻한 스칼렛, 파랑은 보라색으로 기울지 않는 밝은
  애저를 유지한다. 야간의 차가운 조명 아래 두 팀이 같은 보랏빛 중간색으로 수렴하는 것을
  피하기 위한 조합이다.
- 팀 색을 상의에만 두지 말고 양말에도 반복한다. 측면·후면·가림 상황에서 남는 가장 큰
  보조 신호다.
- 파랑 팀의 딥 네이비 패턴은 몸통 면적의 약 35–40%를 넘기지 않는 것을 권장한다.
  그보다 많으면 어두운 피치와 합쳐져 선수 상체가 작게 보인다.
- 빨강 팀 버건디도 명암용 보조색으로만 사용한다. 주 스칼렛 면적을 최소 60% 남긴다.
- 40px 부근에서는 얇은 파이핑, 작은 엠블럼, 복잡한 칼라, 관절 디테일에 렌더 비용을
  쓰지 않는다. 약 3px 이상 남는 번호·소매 끝·큰 패턴만 유효하다.
- CanvasTexture로 옮길 때는 색상 텍스처를 sRGB로 취급하고, 야간 키라이트는 중립에
  가깝게 유지하는 편이 이 팔레트의 빨강/파랑 간격을 보존한다.

## 최종 프롬프트 세트

모든 생성에는 다음 공통 조건을 적용했다.

> `stylized-concept`, production asset이 아닌 절차 생성 참조, 코드로 재현 가능한
> primitive 기반 low-poly, 큰 색면과 선명한 실루엣, 야간 경기장 키라이트,
> 실존 인물 닮은꼴 금지, 실존 구단·국가대표 킷·엠블럼·스폰서·브랜드·FIFA·월드컵
> 요소 금지, 워터마크와 서명 금지.

| 프롬프트 대상 | 최종 변형 조건 |
|---|---|
| 선수 4종 | 외모 계열 2종 × 팀 컬러 2종, 동일 가상 인물의 정면·오른쪽 측면, 중립 자세, 6.5등신, 굵은 팔다리와 큰 부츠, `#00FF00` 완전 단색 배경 |
| 빨강 킷 | 스칼렛/버건디/아이보리, 왼쪽부터 무지·횡스트라이프·새시, 위 앞면·아래 뒷면, 숫자 8만 사용 |
| 파랑 킷 | 애저/딥 네이비/흰색, 왼쪽부터 무지·횡스트라이프·새시, 위 앞면·아래 뒷면, 숫자 8만 사용 |
| 골대 | 같은 골대의 정면·높은 사선, 단순 흰 프레임과 정사각 네트, 사람·공·경기장 배경 없음 |
| 코너 플래그 | 흰 폴, 노랑/코럴 삼각 플레인, 메인 사선·작은 측면, 사람·공·경기장 배경 없음 |
| 관중 패턴 | 화면 전체를 채운 얼굴 없는 블록 군중, 어두운 질량 70%, 빨강/파랑 균형, 텍스트·깃발 없음 |
| 광고판 | 가상 조어 4종만 각 한 번 사용, 굵은 기하 아이콘과 대문자, 높은 원거리 대비 |
