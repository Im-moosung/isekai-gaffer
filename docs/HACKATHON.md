## 주제
실제 월드컵 데이터를 활용한 **동적 인터랙션 웹서비스** 구현.
사용자가 축구 감독이 된 것처럼 전술을 직접 구성·조작(드래그, 클릭, 배치)할 수 있어야 함.

### 공식 예시
- 드래그앤드롭으로 선수 배치 + 포메이션 구성하는 전술 보드
- 상대팀 데이터 분석 → AI 맞춤 전술 추천
- 실제 경기 데이터 기반 "내가 감독이었다면" 시나리오 시뮬레이션
- 경기 스탯 보며 교체·전술 변경을 지시하는 인터랙티브 서비스
