# 중계 음성 녹음 규격

TTS를 미리 녹음한 음원으로 대체하기 위한 목록과 규칙. 목록은 `commentary-lines.tsv`.

## 규모 (60경기 실측, 2026-07-31)

| | 개수 |
|---|---:|
| 템플릿 총계 | **145** |
| 캐스터 | 98 (정적 7) |
| 해설위원 | 47 (정적 18) |
| **정적**(치환 없음 — 그대로 녹음 가능) | **25** |
| 동적(이름·팀·숫자 치환) | 120 |

문장 수가 템플릿 수보다 훨씬 많은 이유는 **선수 이름·팀·분·스코어가 치환**되기 때문이다.
시드와 대진이 바뀌면 조합이 무한히 늘어나므로 **문장 단위 전량 녹음은 불가능**하다.

## 방식 두 가지

### A. 조각 이어붙이기 — 전 경기 커버

| 조각 | 개수 |
|---|---:|
| 선수 이름 | 312 |
| 팀 이름 | 12 |
| 분 라벨(`전반 27분`) | ~100 |
| 스코어(`일 대 영`) | ~40 |
| 템플릿 프레임(앞·뒤 토막) | ~200 |
| **합계** | **약 660** |

조각마다 **끝 억양을 평평하게** 유지해야 붙였을 때 안 튄다.

### B. 데모 한 경기 통째 — 약 106 발화

시드 하나를 고정해 그 경기의 발화만 녹음한다. 이음매 0, 억양 자연스러움.
시연영상용으로는 이쪽이 낫고, 다른 경기는 TTS로 떨어진다.

## 포맷 (어느 방식이든 공통)

- `.mp3` 128kbps 이상 또는 `.opus`
- **48kHz 모노**
- **라우드니스 −16 LUFS로 통일** — 조각마다 음량이 다르면 붙였을 때 계단이 생긴다
- 앞뒤 **무음 50ms 이내**로 트림. 무음이 길면 이음매가 벌어진다

## 길이

- 한 발화 **최대 9초**(`playback.MAX_DWELL_MS = 9000`). 넘으면 다음 분에서 잘린다
- 골 장면은 캐스터 + 해설이 합쳐 약 9초라 **각각 4.5초 안쪽**이 안전하다

## 화자 둘

| | 성격 | 현재 TTS 설정 |
|---|---|---|
| **캐스터** | 무슨 일이 일어났는지. 골에서 톤이 올라간다 | rate 0.95~1.05 / pitch 1.00~1.35 |
| **해설위원** | 왜 그런지. 낮고 느리다 | rate 1.00 / pitch **0.75** |

pitch 간격 0.55로 구분하고 있으므로 **실제로 다른 목소리**여야 한다.
해설위원은 47개 중 18개가 정적이라 **적은 투자로 효과가 크다**.

## 파일명

```
caster/<템플릿id>.mp3      예: caster/goal.opener.1.mp3
analyst/<템플릿id>.mp3
name/<선수id>.mp3          (A안만)
minute/<분>.mp3            (A안만)
```

`commentary-lines.tsv`의 `파일명` 열이 그대로 경로다.

## 라이선스 주의

외부 모델·음원을 쓰면 라이선스를 확인해 원장에 기록한다(프로젝트 규칙).
검토한 것 중:

- **KRAFTON Raon-Speech** — 코드는 Apache 2.0이나 **모델 가중치는 CC BY-NC 4.0**(9B·21B 둘 다).
  상금이 걸린 대회 출품이 "NonCommercial"에 해당하는지 판단이 필요하고, 출처 표기(BY)가 필수다.
  또한 CUDA 전제라 Apple Silicon에서 실행이 보장되지 않는다.
