# Qwen3-TTS 축구 중계 보이스 옵션

같은 한국어 대본으로 생성한 남성 캐스터 3종과 해설위원 3종입니다. 파일명에 있는 별칭을 그대로 사용하면 나중에 선택한 목소리를 다시 식별할 수 있습니다.

| --- | --- | --- | --- | --- |

| C2 | **질주** | 캐스터 | 빠르고 날카로운 속도형 | [caster-C2-질주.wav](<caster-C2-질주.wav>) |
| C3 | **정석** | 캐스터 | 깊고 안정적인 정통형 | [caster-C3-정석.wav](<caster-C3-정석.wav>) |
| A1 | **전술판** | 해설위원 | 논리적이고 전문적인 전술 분석형 | [analyst-A1-전술판.wav](<analyst-A1-전술판.wav>) |
| A2 | **침착** | 해설위원 | 부드럽고 편안한 복기형 | [analyst-A2-침착.wav](<analyst-A2-침착.wav>) |
| A3 | **열정** | 해설위원 | 감탄과 현장감이 살아 있는 컬러 해설형 | [analyst-A3-열정.wav](<analyst-A3-열정.wav>) |

## 선택 기록

- 캐스터 후보: **C3 정석**, 1.2배속 비교 중
- 해설위원 후보: **A3 열정**, 1.5배속 비교 중
- 최종 속도 선택: 미확정
- 예시: `캐스터 C2 질주 + 해설 A1 전술판`
