# 들어 볼 것 — 음역이 흔들리는가

숫자로는 판정할 수 없다. `tools/tts/f0.py`는 numpy 없는 순수 파이썬 자기상관이라
0.5초짜리 이름 조각에서 옥타브 배증 오검출이 나고, 이번 실측에서는 **기준 배치
자신의 산포가 6.4반음**으로 나왔다(그럴 리 없는 값이다). 그래서 귀로 판정한다.

전부 `tools/tts/sample.py`가 **런타임과 같은 규칙**으로 이어 붙였다
(조각 사이 90ms, 줄 사이 260ms). 지금 있는 배치는 넷이다:

| 배치 | 무엇 | 요청 |
|---|---|---|
| C01·C02 | 입장 소개 완결 문장 26개 (plain 16 / 10) | 2회 |
| C03·C04 | 한국 이름 조각 16개 (carrier 8 / 8) | 2회 |
| A14 | 해설위원 문장 6개 (다른 모델) | 1회 |

| 파일 | 듣는 것 |
|---|---|
| `01-한줄-이음매-같은배치` | 한 줄 안의 이음매 하나. **같은 요청**에서 온 두 조각 |
| `02-한줄-이음매-배치경계` | 같은 문장인데 이름만 **다른 요청**(C04). 01과 나란히 들어라 |
| `03-수비묶음-C03만` | 그룹 도입 + 이름 넷. 한 요청 안의 이름끼리 |
| `04-수비묶음-C03과C04혼합` | 같은 도입 + **두 요청이 섞인** 이름들. 03과 비교 |
| `05-입장-앞부분-통짜` | 실제 입장 순서 그대로 — 이게 유저가 듣게 될 소리다 |
| `06-중원과-해설-마무리` | 캐스터 → **해설위원**(다른 모델) 전환 |
| `07-팀도입-연속` | 완결 문장만 연달아. 이름 없는 대조군 |
| `08-이름만-연속-두배치` | 이름 여덟만 연달아. C03 넷 → C04 넷. **여기서 갈리면 배치가 범인이다** |

## A/B — 음역 정렬을 걸까 말까

`05`/`08`은 정렬 **적용**이고, `05x`/`08x`는 **정렬 없음**이다. 같은 조각으로 만들었다.

정렬(`join.py --match-register`)은 조각의 중앙 F0를 기준 음역으로 당기되 **±5반음을
넘으면 당기지 않는다**(그 이상은 성대 특성까지 변해 다른 사람이 된다). 그런데 이번
캐스터 이름 조각들은 추정치가 기준보다 5~9반음 높게 나와, **일부만 당겨지고 일부는
그대로 남는다**. 그게 오히려 조각들을 더 벌려 놓을 수 있다.

- `05` vs `05x`, `08` vs `08x`를 나란히 들어라.
- 정렬한 쪽이 더 고르면 그대로 간다.
- 정렬 안 한 쪽이 더 자연스러우면 `assemble.py --no-align`을 기본으로 바꾼다.
