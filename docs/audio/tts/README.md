# Gemini TTS 전량 생성 — 무엇을 몇 번의 요청으로 굽는가

프로토타입 판정(`docs/audio/tts-proto/README.md`)에서 **B안(캐리어 절단) 확정**을 받은
뒤의 실행 계획이다. 여기 있는 숫자는 전부 **코드를 돌려서 잰 값**이다 — 추측이 없다.

| | |
|---|---|
| 캐스터 | **Puck** / `gemini-2.5-flash-preview-tts` |
| 해설위원 | **Iapetus** / `gemini-3.1-flash-tts-preview` |
| 병목 | **모델당 RPD 10** (TPM 10K는 실측 92토큰이라 남아돈다) |
| 후처리 | `atempo=1.15` · `loudnorm=I=-16:TP=-1.5:LRA=11` · mp3 64k |
| 런타임 | **호출하지 않는다.** 빌드 타임에 구워 `public/tts/`에 커밋한다 |

> 런타임 호출을 금지하는 이유는 약관이다. 배포물이 API Client가 되면 연령·지역 제한이
> 걸린다. 생성물 자체는 소유권 주장이 없고 preview 모델도 프로덕션 사용이 허용된다.

## ① 이름 범위 — 312명이 아니라 147명이다

`tools/tts/roster.mjs`가 캠페인 24시드를 실제로 시뮬레이션해서(입장 소개 + 경기 중계 +
교체) **이름이 발화되는 선수**를 셌다.

| 팀 | 스쿼드 | 발화됨 | 클립 대상 |
|---|---:|---:|---:|
| 대한민국 | 26 | 16 | **26** (유저가 라인업을 바꾸므로 전원이 후보) |
| 나머지 11팀 | 각 26 | 각 11 | 각 **11** (AI는 `pickBestXI`가 결정론적으로 XI를 고정한다) |
| 합계 | 312 | | **147** |

- AI 팀은 24시드 전체에서 **선발 XI 11명을 넘어서지 않았다**. 교체로 들어온 선수도
  이름이 불린 적이 없다(엔진의 AI 교체가 이름 템플릿을 타지 않는다).
- 한국만 예외다. 출장정지·유저 조작으로 XI가 바뀌므로 26명 전원을 후보로 잡는다.
  (24시드 자동 진행만으로도 16명이 실제로 불렸다.)

### 화자 분포 — 해설위원 이름 클립은 **0개로 만들 수 있었다**

| 화자 | 이름이 든 문장 | 비율 |
|---|---:|---:|
| 캐스터 | 3,365 | 95.9% |
| 해설위원 | 145 | 4.1% |

해설위원이 이름을 부르는 템플릿은 **단 하나**(`an.save.1`)였고, 그 이름은 언제나
**선방한 골키퍼**였다. 그래서 이름을 역할어로 바꿨다 — 뜻이 그대로다.

```
- {선수}, 자리 선정이 좋았습니다.
+ 골키퍼, 자리 선정이 좋았습니다.
```

해설위원 모델의 RPD 10이 통째로 남는다. **적용했다**(`src/game/commentary.ts`).

## ② 조사 역할 — 실제 병목은 조사가 아니라 예산이었다

프로토 README의 권고는 "TSV의 조사 7종(`∅·의·이/가·은/는·을/를·에게·입니다`)을
`∅ + 이/가` 2종으로 줄여 312×7을 312×2로"였다. 재작성안은 아래에 남긴다. 다만
**지금은 적용하지 않았다** — 판단 근거는 §③이다. 경기 중 중계는 이번 마감 안에
mp3로 구울 수 없어서, 지금 20문장을 고치면 *돌아오는 것 없이* 출시 중인 중계 문장만
흔든다(문장 감사 baseline·동시 진행 중인 밸런스 갈래).

재작성안(소리 내어 읽어 확인한 것):

| id | 지금 (조사) | 재작성 (∅ 또는 이/가) |
|---|---|---|
| `foul.1` | {P}**의** 반칙으로 흐름이 끊깁니다. | {P}**,** 반칙입니다. 흐름이 끊깁니다. |
| `foul.2` | {P}**는** 늦게 들어갔습니다. | {P}**,** 늦게 들어갔습니다. |
| `miss.1` | {P}**의** 슛, 골문을 벗어납니다. | {P}**,** 슛이 골문을 벗어납니다. |

| `shot.2` | {P}**의** 슈팅, 골문을 향합니다! | {P}**,** 슈팅이 골문을 향합니다! |
| `shot.4` | {P}**는** 과감하게 노려봅니다. | {P}**,** 과감하게 노려봅니다. |
| `shot.7` | {P}**의** 발끝을 떠납니다! | {P}**,** 발끝을 떠납니다! |

| `yellow.3` | {P}**는** 경고를 피하지 못합니다. | {P}**,** 경고를 피하지 못합니다. |
| `red.1` | 주심이 {P}**를** 그라운드 밖으로 내보냅니다. | {P}**,** 여기서 그라운드를 떠납니다. |
| `streak.fouls.1` | 또 {P}**입니다**. 반칙이 잦네요. | {P}**,** 또 걸립니다. 반칙이 잦네요. |
| `goal.equalizer.1` | 따라붙습니다! {S}! {P}**의** 골! | 따라붙습니다! {S}! {P}**,** 골입니다! |
| `goal.extra.1` | {T}, 한 골 더 달아납니다! {P}**의** 골! | {T}, 한 골 더 달아납니다! {P}**,** 골입니다! |

| `goal.consolation.2` | 영패는 면했습니다. {P}**의** 골입니다. | 영패는 면했습니다. {P}**,** 골입니다. |

나머지 이름 템플릿(`{P}!`, `{P}, 선방!`, `{P}가 손끝으로 걷어냅니다!` …)은 이미
`∅`이거나 `이/가`다 — 손댈 것이 없다.

### 적용한 재작성 두 건 (입장 소개 — 이번 범위)

| 어디 | 전 | 후 | 왜 |
|---|---|---|---|
| 골키퍼 호명 | `골키퍼, 김승규.` | `골키퍼, 김승규**입니다**.` | 그룹 마지막 호명(`…입니다.`)과 **같은 형태**가 되어 이름 조각이 2형태로 닫힌다 |
| `an.save.1` | `{선수}, 자리 선정이…` | `**골키퍼**, 자리 선정이…` | 해설위원 이름 클립 12 → **0** |

### 이름 조각을 왜 **2형태**로 굽는가 (`{이름},` / `{이름}입니다.`)

`입니다`를 공용 조각으로 빼면 조각 수가 147개로 반이 되지만, `이한범`+`입니다`의
이음매가 **음절 한복판**(범+입 → [버빔])에 떨어져 연음이 깨진다. 조사를 템플릿이
아니라 이름 클립에 붙인 것과 **똑같은 이유**다. 받침 없는 이름은 안 깨지지만,
이름의 절반만 자연스러운 건 품질이 아니다.

## ③ 매니페스트와 예산 — 조별리그 3경기까지가 하루치다

`tools/tts/manifest.mjs`가 ①·②의 실측을 배치(=요청 1회)로 접는다.

**배치는 두 종류이고 절대 섞지 않는다.** 조각 수가 달라 `silencedetect` 계약이 깨진다.

| 종류 | 프롬프트 | 조각 | 쓰임 |
|---|---|---:|---|
| `plain` | 완결 문장 N개 | N | 입장 소개 문장(`네 명의 수비가 출전합니다.`) |
| `carrier` | `A …… B` 캐리어 N개 | 2N | 이름·조각. 머리=문중 억양, 꼬리=문말 하강 |

캐리어는 **문법적으로 온전한 문장**이다. 비문을 읽히면 억양이 무너진다.

```
머리 절단  {이름} …… 지금 좋습니다.        →  `{이름},`
꼬리 절단  이 선수는 …… {이름}입니다.      →  `{이름}입니다.`
머리 절단  골키퍼 …… 자리를 잡습니다.      →  `골키퍼,`
```

### 확정 매니페스트 (scope=group, batch=16)

| | 클립 | 요청 | RPD 10 |
|---|---:|---:|---|
| 캐스터 | 145 | **10** | 하루에 들어간다 (여유 0) |
| 해설위원 | 6 | **1** | 하루에 들어간다 (여유 9) |
| 합계 | **151** | **11** | 추정 배포 용량 **1.51 MB** |

덮는 범위: **대한민국 26명 전원 + 조별리그 3팀(체코·멕시코·남아공) 선발 XI 33명**
+ 입장 소개 문장 32개 전부. 즉 **누구나 반드시 치르는 조별리그 3경기의 입장 연출이
통째로 Gemini 목소리**로 나온다. 토너먼트 8팀은 `speechSynthesis` 폴백이다.

### 전 팀을 덮으려면 — 하루에 안 들어간다

| 안 | 범위 | 배치 | 캐스터 요청 | 판정 |
|---|---|---:|---:|---|
| **A (확정)** | 조별리그 + 한국 | 16 | **10** | 하루. 여유 0 |
| B | 조별리그 + 한국 | 20 | **8** | 하루. 여유 2(재시도용) — 배치를 키운 만큼 음역이 흩어진다 |
| C | 전 12팀 | 16 | 21 | **3일** — 마감 전에 불가능 |
| D | 전 12팀 | 24 | 15 | **2일** — 마감 전에 불가능 |

마감(2026-08-03 10:00 KST)까지 남은 한도 창은 사실상 **하나**다. 태평양 08-02일
(KST 08-02 16:00 ~ 08-03 16:00)이 마감을 덮는 마지막 창이고 거기서 캐스터 10회를
받는다. C·D는 물리적으로 불가능하다.

**더 줄여야 한다면** 순서는 이미 매니페스트에 박혀 있다(우선순위 = 배치 순서):
`C01·C02` 문장 → `C03~C06` 한국 26명 → `C07~C10` 조별리그 3팀. 뒤에서부터
잘라도 앞은 그대로 쓸 수 있다. 남는 요청이 있으면 `--scope all`로 다시 접어
토너먼트 팀을 이어 굽는다(이미 받은 배치는 건너뛴다).

### 재개 — 원본 wav가 체크포인트다

```
out/tts/raw/{배치}.wav      ← 있으면 그 배치는 다시 요청하지 않는다
out/tts/work/{배치}.norm.wav 조각 잘라내기 작업물
public/tts/{키}.mp3          배포물
public/tts/index.json        런타임 조회표 — **실제로 존재하는 mp3만** 싣는다
```

- `run.py`는 429/500이 나면 **그 자리에서 멈춘다.** 재시도하지 않는다 —
  재시도가 RPD를 태우는 게 가장 비싼 실패다.
- 자르기가 어긋나면(`조각 수 != 기대`) `assemble.py`가 **죽는다.** 조용히 어긋난 채
  붙이면 엉뚱한 이름이 방송되고, 그건 재생 시점에야 들킨다. 원본 wav는 남아 있으니
  `--min-sil`·`--noise`만 바꿔 다시 돌린다. **API를 다시 부르지 않는다.**

### 조립 순서와 그 이유

```
raw.wav ──loudnorm──▶ norm.wav ──silencedetect──▶ 조각 ──음역정렬──▶ atempo ──▶ mp3 64k
```

- **loudnorm은 자르기 전에.** 0.5초 조각에 걸면 측정 구간이 모자라 조각마다 게인이 튄다.
  배치 전체(30~70초)에 한 번 걸어야 모든 조각이 같은 게인을 받는다.
- **자르기는 원본 타이밍에서.** atempo를 먼저 걸면 문장 사이 쉼도 줄어 문턱이 흔들린다.
- **음역 정렬은 조각마다.** 캐스터 `plain` 배치의 중앙 F0가 기준이다. ±5반음을 넘으면
  당기지 않고 경고한다 — 그 이상은 다른 사람 목소리가 된다.

## ④ 런타임 배선 — mp3 우선, `speechSynthesis` 폴백

`src/audio/commentary-mp3.ts` (새 모듈) + `src/audio/commentary-tts.ts` (분기 추가).
**기존 `speechSynthesis` 경로는 한 줄도 지우지 않았다.** 클립은 일부 팀만 덮으므로
폴백이 비상구가 아니라 **정상 경로**다.

- **AudioContext를 만들지 않는다.** `sfx.audioBus()`가 유저 제스처에서 연 것을 빌린다.
  그래야 음소거 토글 **하나**(`sfx.setMuted`)가 효과음·BGM·해설을 함께 끊는다.
  버스가 없으면(제스처 전·jsdom·SSR) 조용히 `false` → 폴백.
- **`HTMLAudioElement`를 쓰지 않는다.** jsdom에 반쪽만 있어 테스트가 환경에 따라 갈린다
  — `bgm.ts`가 Web Audio만 쓰는 것과 같은 이유다. fetch + `decodeAudioData` +
  `AudioBufferSourceNode`만 쓴다. 덕분에 **오디오 파일이 하나도 없어도 테스트가 돈다**
  (`src/audio/__tests__/commentary-mp3.test.ts`).
- **재생 속도**(1x/1.5x/2x)는 `playbackRate`로 간다(상한 2배).
- **순서 보존**: 대본(`speakScripted`)은 큐 꼬리 시각(`queueEndsAt`)에 이어 예약한다.
  mp3 실길이가 `estimateSpeechMs` 추정과 달라도 순서는 절대 뒤집히지 않는다.
- **전부 아니면 전무**: `beginScript(대본 전체)`가 한 줄이라도 못 덮으면 대본 전체를
  `speechSynthesis`로 낸다. 스물 몇 줄 중 몇 줄만 mp3면 한 사람이 줄마다 목소리를
  바꾸는 소리가 난다.
- **일시정지는 mp3에 걸지 않는다.** `AudioBufferSourceNode`는 멈추면 이어 재생할 수
  없고(끊으면 그 문장이 사라진다), 조각이 0.5~2초라 얼리지 않아도 어긋나지 않는다.

### 아직 남은 한 줄 — `MatchScreen.tsx` 훅

`beginScript`/`endScript`를 입장 연출에 걸어야 mp3가 실제로 울린다. `src/ui/**`는
다른 갈래 소유라 **여기서 고치지 않았다.**

```ts
// expandEntrance() 안, setEntranceScr(scr) 직후
ctts.beginScript(scr.beats.map(b => b.speech))
// handleEntranceDone() 안, ctts.stopAll() 뒤
ctts.endScript()
```

이 두 줄이 없으면 `scriptMp3`가 계속 false라 **지금과 완전히 같게 동작한다**(회귀 0).
